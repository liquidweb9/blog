# FIFA Creative Studio AI 足球赛事视频处理系统

## 项目简介

参与 FIFA 足球赛事短视频自动化生产系统研发，构建“回放检测、足球检测与追踪、智能裁切、语音识别、视频拆条与合成”处理链路，将 16:9 赛事视频自动转换为 9:16 竖版和 1:1 方形集锦视频。

## 视频理解

- 使用 TransNetV2 检测镜头边界，结合 CLIP 特征相似度识别回放 Logo 与回放片段
- 基于 PaddleDetection RT-DETR v3 完成足球小目标检测
- 引入球场 ROI、边线过滤、坐标跳变约束与置信度分级，减少观众席、广告牌及边线区域误检
- 使用 U-Net 球场分割与单应性变换完成场内判定和坐标映射

## 智能裁切

设计带死区的 EMA 平滑、最大移动步长约束与贝塞尔插值算法，根据足球轨迹动态调整裁切中心和缩放范围，减少竖屏画面抖动与中心突变。

## 服务化与部署

- 使用 FastAPI 封装统一任务接口
- 接入 faster-whisper 与 FFmpeg，完成语音识别、视频拆条、音频保留和多比例编码
- 使用线程池与任务队列支持批量执行、失败重试、状态查询与缓存清理
- 参与 Docker、Kubernetes、NFS 与 GPU 环境部署，并补充资源监控接口
