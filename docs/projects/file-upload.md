# 基于属性基加密的安全文件共享系统

**角色：全栈开发者** · `2024.12—2025.04`

## 项目简介

针对传统链接或密码分享难以实现细粒度权限控制，以及大文件上传中的断点续传、重复上传和并发一致性问题，设计并实现基于属性基加密（ABE）的安全文件共享系统。

## 后端架构

- 使用 Spring Boot 3、MyBatis-Plus、MySQL 与 Redis 搭建服务端
- 按 `core`、`web`、`common`、`storage`、`cache`、`lock` 等模块拆分业务能力
- 使用 Redis 分布式锁与本地锁控制上传状态，保障高并发场景下的数据一致性

## 文件能力

- 分片并发上传与断点续传
- 失败重试与文件合并校验
- Hash 秒传与内容去重
- 多用户数据空间隔离

## 加密与访问控制

通过 Node.js 调用独立 Java ABE 组件，完成文件加解密及属性策略校验，支持公开、私有、访问密码和属性策略等分享模式。

## 客户端

使用 Vue 3 与 Element Plus 开发前端，并使用 Electron 完成跨平台桌面端封装。
