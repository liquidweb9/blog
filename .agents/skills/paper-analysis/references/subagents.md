# 分步 subagent 协作规范

在宿主允许任务委派的前提下，主代理可为当前论文研读分步使用 subagent。使用当前环境提供的通用研究或分析能力，不依赖特定 agent 名称、调用 API 或模型配置。无委派工具时，主代理执行同样阶段。

## 1. 推荐依赖关系

```text
主代理：确认输入、取得全文、锁定版本、建立共享研读包
    ↓
阶段 A：来源与关键主张核对（资料复杂时委派，简单时主代理完成）
    ↓ 主代理冻结版本、术语、符号与案例计划
阶段 B：方法、原图、公式与例子拆解 ─┐
阶段 C：实验、消融、成本与结论审计 ─┴─ 可并行，任务不重叠
    ↓ 主代理核实冲突、组织大纲、整合并统一成稿
阶段 D：独立核稿，核查证据、例子与阅读连贯性
    ↓ 主代理定点修改、站点检查、交付
```

不要在版本未确定时分别让多个 agent 从网上各找一版论文写稿；也不要让每个 agent 各写一篇完整札记后拼接。

## 2. 交接契约

每次委派必须提供以下内容，subagent 不继承主代理全部上下文：

1. **目标与范围**：当前阶段要回答的问题、明确不负责的相邻任务。
2. **固定材料**：主版本文件/URL、必要附录、页码说明、共享研读包或相关摘录。
3. **上下文**：目标读者、术语/符号、贯穿案例、文章意图、相关已有笔记。
4. **写入权限**：默认只读分析并返回结果；确需写中间文件时指定唯一文件，禁止多人编辑同一文章。
5. **返回格式**：结论、原文定位、推导或计算、确认状态、影响结论的疑问；不用整篇长文。
6. **完成标准**：核查哪些主张/例子、如何验算，以及不能从资料得出的部分。

共享研读包由主代理维护；最终正文、来源索引和导航由主代理统一编辑。图像提取可单独委派指定文件，但必须返回原图号、页码、裁剪记录和实际清晰度检查结果。

不默认递归委派。已经委派的工作主代理不再重复探索，而是做不重叠任务并在收件后裁决具体冲突。

## 3. 可改写的委派提示词

### A. 来源与主张核对

```text
只做资料核对，不写最终文章，不再委派。
任务：基于 {主版本 PDF 路径或官方 URL}，核对标题、版本、全文结构、
主要贡献和主实验配置。用户目标是 {读者/重点}。
补充材料：{路径/URL}。现有来源记录：{路径或摘要}。
若其他版本数字不同，仅列差异，不替换主版本。
返回：
1. 版本与全文可读性；
2. 主张—章节/图表/页码—适用条件—确认状态表；
3. 后续必须读的附录；
4. 尚缺资料及是否阻塞完整研读。
不得把摘要或宣传语当作全部证据，不补造官方实现入口。
```

### B. 方法、原图与例子拆解

```text
只读分析，不修改最终文章，不再委派。
主版本：{路径}；研读包：{路径或必要摘录}。
术语和符号：{约定}；贯穿案例：{输入/期望输出/已有方案失败点}。
任务：按执行顺序拆解 {章节/模块}，对应原图 {图号/页码} 和关键公式。
逐步交代输入、操作、中间结果、输出、训练/推理、信息可见性与假设。
沿贯穿案例走通核心流程，必要时提出少量局部数值例子并验算。
返回：模块数据流、图解要点、公式解释、例子中间量和结果、证据位置。
区分原文公式、等价推导、说明性参数和未确认细节。
不负责主实验数据表，不为简化案例改变论文机制。
```

### C. 实验与成本审计

```text
只读核查，不改最终文章，不再委派。
主版本：{路径}；研读包：{路径或摘录}。
任务：核实 {主表/关键消融/泛化实验/成本}，不是重复拆解全部方法。
返回每项数据的原文位置、配置、指标方向、比较对象、数值和能支持的结论。
检查版本、标签量、候选数、模型池、数据划分、oracle/转导设置和预算差异。
验算拟用于正文的百分点/比例/成本；口径冲突保留原始数字和疑问，
给出可以稳妥用于正文的替代表述，不把未解决的比例写成确定事实。
不要因为结果表缺少某项实验就编造解释或显著性。
```

### D. 独立核稿

```text
只审校，不自行改文件，不再委派。
初稿：{路径}；主版本与研读包：{路径}；写作规则：{路径或摘要}。
检查：核心主张和配置可追溯；图/公式/符号一致；说明性例子算对且不改变机制；
事实、推导和设想分清；正文能从输入走到输出；无重复背景和突兀拼接；
自检备注已进注释，但必要限制和图源署名仍可见。
按「必须修正/建议改善」返回，每项列初稿位置、问题、依据和最小修改建议。
只报告有证据或具体阅读影响的问题，不按个人喜好推翻结构，
不要求为了形式凑图、例子、章节或反复扩展检索。
```

## 4. 统稿与回收

- 主代理先裁决版本、符号和配置冲突，再整合文字；有争议的来源不以多数 agent 意见定真假。
- 对无证据推测，删去确定性表述或保留在自检；对实质性不确定性，正文保留适当限制。
- 把重复案例合并为同一条叙事，统一标题、符号、术语和引导句。
- 核稿后围绕明确缺陷定点修改；仅在新改动或未解决问题需要时再核查，不无限循环审稿。
- subagent 的返回是工作资料，不直接作为读者正文或最终向用户的长篇汇报。
