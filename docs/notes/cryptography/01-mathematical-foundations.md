# 密码学数学基础

---

## 第1章 概率、信息论与计算复杂性

### 1.1 概率论基础

#### 随机变量与概率分布

随机变量是将随机试验的结果映射到实数的函数，分为离散型和连续型。概率分布则描述了随机变量取各个值的可能性。在密码学中，密钥、明文、密文、随机数等都被建模为随机变量，其分布决定了攻击者猜测成功的概率。

例如，若密钥 $K$ 均匀分布在 $\{0,1\}^n$ 上，则 $P(K=k) = 2^{-n}$，攻击者一次猜中密钥的概率是 $2^{-n}$，这是密码学中"安全性"的根本来源——让攻击者猜中的概率小到可忽略。

**Insight**：密码学所有安全性的本质，就是把攻击者的优势归结为"猜对一个均匀分布的随机变量"。无论方案多复杂，最终的安全归约几乎总是落到"敌手无法以不可忽略概率区分两个分布"这个事实上。

#### 条件概率与贝叶斯公式

条件概率 $P(A|B)$ 表示在事件 $B$ 发生的条件下 $A$ 发生的概率。贝叶斯公式描述了后验概率与先验概率的关系：

$$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$

在密码学中，贝叶斯公式用来分析敌手获取某些信息后对未知量的推断能力。如果密文不泄露明文的任何信息，那么 $P(\text{明文}=m \mid \text{密文}=c) = P(\text{明文}=m)$，这正是完美保密的条件。

**Insight**：设计密码方案的关键就是让敌手的后验概率等于先验概率——即观察密文后，敌手对明文的认知没有任何更新。

#### 期望、方差与协方差

期望 $E[X]$ 是随机变量的加权平均，方差 $\text{Var}[X] = E[(X - E[X])^2]$ 衡量分布的离散程度，协方差 $\text{Cov}[X,Y] = E[(X - E[X])(Y - E[Y])]$ 衡量两个变量的线性相关性。

在密码学中，期望用于分析算法的平均运行时间（期望多项式时间算法），方差用于评估随机数的统计质量。如果密钥生成器的输出方差异常小，说明某些密钥出现概率过高，攻击者可优先尝试。

**密码学场景**：分析穷举搜索攻击时，找到密钥的期望步数是 $2^{n-1}$（对均匀分布）。分析侧信道攻击时，功耗与数据位之间的协方差被用来提取密钥比特。

#### 独立性与统计距离

两个随机变量 $X$ 和 $Y$ 独立当且仅当 $P(X=x, Y=y) = P(X=x)P(Y=y)$ 对所有 $x,y$ 成立。

**统计距离（Statistical Distance）** 是衡量两个概率分布差异的核心工具：

$$\Delta(X,Y) = \frac{1}{2} \sum_{x} |P_X(x) - P_Y(x)|$$

如果 $\Delta(X,Y) \le \epsilon$，称 $X$ 和 $Y$ 是 $\epsilon$-接近的。统计距离满足三角不等式，且具有以下性质：

1. **最大区分优势**：任何（计算能力无上限的）区分器区分 $X$ 和 $Y$ 的最大优势就是 $\Delta(X,Y)$
2. **数据加工不等式**：对任意函数 $f$，$\Delta(f(X), f(Y)) \le \Delta(X,Y)$

**Insight**：统计距离是"信息论不可区分性"的精确度量。密码学中，当我们说两个分布"统计不可区分"时，即 $\Delta(X,Y) \le \text{negl}(n)$。这是可证明安全理论的基石——只要两个分布在统计上足够接近，敌手就无法利用它们的行为差异来攻破方案。

实际中，统计距离常用来分析伪随机生成器的输出与真随机分布的差距。如果 $\Delta(\text{PRG}(U_n), U_m) \le 2^{-80}$，那么这个PRG在实践中是安全的。

#### Birthday Bound

生日悖论描述了一个反直觉的现象：在 $N$ 个元素中均匀随机选取 $O(\sqrt{N})$ 个样本，出现碰撞的概率约 $1/2$。精确地，从 $N$ 个值中均匀随机取 $q$ 个，至少一个碰撞的概率约为：

$$P(\text{collision}) \approx 1 - e^{-q(q-1)/(2N)} \approx \frac{q^2}{2N} \quad (\text{当 } q \ll N)$$

**生日界**指 $q = O(\sqrt{N})$ 时碰撞概率不可忽略。

**对哈希函数安全性的影响**：

- 输出空间为 $\{0,1\}^n$ 的哈希函数，其抗碰撞安全强度只有 $n/2$ 比特。这是因为攻击者只需计算 $2^{n/2}$ 次哈希就能以高概率找到碰撞
- 这意味着安全哈希函数（如 SHA-256）需要至少 256 比特输出才能达到 128 比特的碰撞安全性
- 生日攻击是哈希函数最有效的通用攻击，不需要任何结构分析

**密码学场景**：
- **数字签名**：攻击者对合法消息和伪造消息分别找 $2^{n/2}$ 个变体，利用生日悖论让两者碰撞，诱导签名者对合法变体签名，从而窃取伪造消息的有效签名
- **生日攻击**的效率远高于穷举

**Insight**：生日界是密码学中"对称性"的代价——你设计的对称空间越大（哈希值、IV等），攻击者利用内部对称性（碰撞）的空间也越大。设计者必须将输出空间扩大到需求安全强度的两倍来对抗这种攻击。

#### Chernoff Bound

Chernoff 界给出了独立随机变量和偏离其期望的概率的上界。设 $X_1, \dots, X_n$ 是独立 $\{0,1\}$ 随机变量，$X = \sum X_i$，$\mu = E[X]$，则对任意 $\delta \in (0,1)$：

$$P(X \ge (1+\delta)\mu) \le e^{-\mu \delta^2/3}$$
$$P(X \le (1-\delta)\mu) \le e^{-\mu \delta^2/2}$$

更一般的形式对任意有界随机变量成立。

**在密码学归约中的作用**：

Chernoff 界是密码学归约证明的"瑞士军刀"。常见的用法包括：

1. **平均情况到最坏情况**：当我们需要证明一个算法在"大多数"实例上工作良好时，Chernoff 界告诉我们，如果可以控制单次实验的失败概率足够小，重复多次后整体失败概率指数衰减
2. **精度放大**：如果区分器的优势只有 $\epsilon$，我们可以运行 $T = O(1/\epsilon^2)$ 次实验并用 Chernoff 界取多数决，将优势放大到接近 1
3. **重置引理**：分析重绕（rewinding）技术时需要估计随机猜测命中的概率

**Insight**：没有 Chernoff 界，密码学归约将无法处理概率误差的累积。它的核心价值在于：当我们需要从"大概率成功"的算法中提取确定性结论时（比如提取离散对数），Chernoff 界提供了误差控制的数学工具。

#### Union Bound

联合界（Union Bound / Boole's Inequality）是最简单的概率不等式：

$$P\left(\bigcup_{i=1}^n A_i\right) \le \sum_{i=1}^n P(A_i)$$

即使不知道事件之间的依赖关系，联合界也总能给出一个保守的上界。

**密码学应用**：

- 在安全归约中，方案的安全性通常依赖于多个事件都不发生。用联合界可以给出：
  $$P(\text{方案被攻破}) \le P(E_1) + P(E_2) + \cdots + P(E_k)$$
  其中 $E_i$ 是各个"坏事件"
- 这使得我们能模块化地分析安全性——分别分析每个坏事件的上界，再求和

**Insight**：联合界是密码学中"最差情况分析"的体现。虽然它很保守（可能高估真实概率），但在可证明安全中，保守意味着安全。如果即使使用联合界，总失败概率仍然可忽略，那么真实的安全性只会更高。这体现了密码学设计中的"安全第一"原则。

### 1.2 信息论基础

#### 信息熵

信息熵衡量随机变量的不确定性，由 Shannon 定义：

$$H(X) = -\sum_{x \in \mathcal{X}} P(x) \log_2 P(x)$$

单位是比特（bit）。当 $X$ 在 $\{0,1\}^n$ 上均匀分布时，$H(X) = n$ 达到最大值。

**密码学意义**：

- **密钥熵**：密钥的不确定性至少应等于安全参数。如果 $H(K) < \log_2 |\mathcal{K}|$，说明某些密钥比其他的更可能出现，攻击者可以优先尝试
- **明文熵**：自然语言（如英文）的熵约为 1-1.5 比特/字符，远低于 8 比特/字符。这就是为什么经典密码（如维吉尼亚密码）容易被频率分析攻破——明文的低熵产生了统计规律
- **熵与压缩**：熵是数据压缩的理论极限，也是伪随机性的度量基础

**Insight**：熵度量的是"平均信息量"，而不是"最坏情况信息量"。密码学中我们通常更关心最小熵 $H_{\min}(X) = -\log_2 (\max_x P(x))$，因为它衡量的是"敌手一次猜中的概率"。一个分布可以有很高的香农熵，但如果某个值出现的概率明显高于其他值，敌手总是猜那个值就行——此时最小熵才是更好的安全性度量。

#### 条件熵

条件熵 $H(Y|X)$ 表示已知 $X$ 后 $Y$ 剩余的不确定性：

$$H(Y|X) = \sum_{x} P(x) H(Y|X=x) = -\sum_{x,y} P(x,y) \log_2 P(y|x)$$

链式法则（信息论的核心工具之一）：$H(X,Y) = H(X) + H(Y|X)$

**密码学场景**：

- 分析已知明文攻击：如果 $H(\text{密钥} \mid \text{密文}, \text{明文})$ 仍然很高，说明密文泄露的密钥信息有限
- 用于论证"知道部分信息后，不确定性降低多少"

#### 联合熵

联合熵 $H(X,Y)$ 度量一对随机变量的总不确定性：

$$H(X,Y) = -\sum_{x,y} P(x,y) \log_2 P(x,y)$$

性质：$H(X,Y) \le H(X) + H(Y)$，等号成立当且仅当 $X$ 和 $Y$ 独立。

**密码学场景**：评估两个随机来源的组合随机性。如果设计者用两个独立的弱随机源生成密钥，联合熵是它们各自熵的和。

#### 互信息

互信息衡量一个随机变量包含另一个随机变量的信息量：

$$I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)$$

互信息是 $P(x,y)$ 和 $P(x)P(y)$ 之间的 KL 散度，非负且对称。

**完美保密的等价条件**：一个加密方案达到完美保密当且仅当 $I(\text{明文};\text{密文}) = 0$，即密文与明文互信息为零。这意味着密文不泄露关于明文的任何信息。

**Insight**：互信息是密码分析的核心工具。古典密码被攻破的本质就是明文和密文之间存在非零互信息。频率分析利用的就是字母频率的统计规律——明文分布（英文文本）和密文分布之间存在很高的互信息，因为加密只是一个固定置换。

#### 完美保密

Shannon 完美保密定义：加密方案 $\Pi = (\text{Gen}, \text{Enc}, \text{Dec})$ 满足完美保密，如果对任意明文 $m_0, m_1$ 和任意密文 $c$，有：

$$P(\text{Enc}_K(m_0) = c) = P(\text{Enc}_K(m_1) = c)$$

即密文的分布独立于明文。等价定义：

1. $P(M=m \mid C=c) = P(M=m)$ — 观察密文后明文的后验分布等于先验分布
2. $I(M;C)=0$ — 明文和密文互信息为零
3. 任何（无计算能力限制的）敌手猜明文的优势为零

**Insight**：完美保密定义的美妙之处在于，它完全不限制攻击者的计算能力——即使攻击者拥有无限计算能力，也无法获得任何优势。这是"信息论安全"的核心特质，也是"计算安全性"要放松的标准。

#### 一次一密为什么具有信息论安全性

一次一密（One-Time Pad）的方案：密钥 $K$ 与明文 $M$ 等长且均匀随机，密文 $C = M \oplus K$。

**安全性证明**：对任意固定的 $c$ 和 $m$，有：

$$P(C=c \mid M=m) = P(K = m \oplus c) = 2^{-n}$$

与 $m$ 无关。因此对任意 $m_0, m_1$：

$$P(C=c \mid M=m_0) = P(C=c \mid M=m_1)$$

满足完美保密定义。

**根本原因**：异或运算在密钥均匀随机的条件下，将明文分布变成了均匀随机分布，无论明文分布如何。密钥的随机性完全"掩盖"了明文的统计特征。

**为什么实际中很少使用一次一密**：

1. **密钥长度和明文相同**：如果双方能安全交换与明文等长的密钥，为什么不直接交换明文？
2. **密钥不能重复使用**：如果 $C_1 = M_1 \oplus K$，$C_2 = M_2 \oplus K$，则 $C_1 \oplus C_2 = M_1 \oplus M_2$，泄露两条明文的差异
3. **密钥管理的困难**：对于大规模通信，长密钥的分发和存储不现实

**Insight**：Shannon 证明了**完美保密的必要条件**是 $H(K) \ge H(M)$，即密钥熵至少等于明文熵。这意味着在信息论意义上，不可能用短密钥实现完美保密。现代密码学放弃了"完美保密"这个要求，转而追求"计算安全"——密钥可以很短，但敌手计算能力有限，无法在多项式时间内攻破。这就是"One-Time Pad ≈ 完美的矛，但无法实际使用"的困境：完美保密只能是理论基准，实际应用中必须向计算安全妥协。

### 1.3 计算复杂性

#### P、NP 与 NP 完全问题

- **P**：在多项式时间内可判定的问题集合（即存在确定性多项式时间算法）
- **NP**：在多项式时间内可验证的问题集合（给定解的"证书"，可在多项式时间内验证其正确性）
- **NP 完全**：NP 中最难的一类问题，任何 NP 问题都可以多项式时间归约到它。如果能多项式时间解决任一个 NP 完全问题，则 P = NP

**密码学的核心假设**：$P \neq NP$。虽然密码学依赖的具体假设（如大整数分解困难）比 P ≠ NP 更强，但如果 P = NP，则现代公钥密码学的基础将崩溃。

**为什么 P ≠ NP 不够用**：
- P ≠ NP 只保证最坏情况下的困难性，但密码学需要**平均情况**下的困难性
- 一个 NP 完全问题可能在"大多数"实例上很容易，只是在某些构造的实例上困难
- 密码学需要的是**在均匀随机的实例上**也很困难的问题
- 因此密码学通常不使用 NP 完全问题，而是使用大整数分解（已知不属于 NP 完全）和离散对数等特定假设

**Insight**：密码学和复杂度理论的关系微妙。密码学需要的是"平均情况困难"和"单向函数的存在性"，而 P ≠ NP 只保证最坏情况困难。事实上，如果存在单向函数，则 P ≠ NP，但反之不一定成立。换句话说，单向函数的存在是比 P ≠ NP 更强的假设。

#### 多项式时间算法

算法 $A$ 的**运行时间** $t(n)$ 是输入长度 $n$ 的函数。如果存在多项式 $p(n)$ 使得 $t(n) = O(p(n))$，称 $A$ 是多项式时间算法。

**为什么密码学用多项式作为"高效"的基准**：

1. **封闭性**：多项式对加法、乘法、复合封闭。多项式个多项式时间的级联仍然是多项式时间
2. **容忍技术变化**：$n^2$ 和 $n^3$ 的区别在理论层面不重要（都是多项式），但在实际实现中差异巨大——不过理论分析中我们忽略常数因子
3. **超多项式的界限**：$n^{\log n}$、$2^{\sqrt{n}}$、$2^n$ 都不是多项式

**密码学中"高效"的含义**：

- 合法用户（加解密、签名验证）必须是多项式时间（最好是线性或近线性）
- 攻击者也被建模为多项式时间算法——这就是"计算安全性"中的"计算"的含义

#### 概率多项式时间算法 PPT

PPT（Probabilistic Polynomial Time）算法在多项式步骤内运行，且有访问随机带的能力——每一步可以抛硬币做随机选择。

**为什么 PPT 是敌手的标准模型**：

1. **随机化是必要能力**：现实中的攻击者可以使用随机化策略（如随机猜密钥），理论模型必须允许
2. **确定性算法的特化**：确定性多项式时间是 PPT 的特例
3. **随机化增强能力**：对于某些问题（如素数判定），随机化算法远快于任何已知确定性算法
4. **BPP**：PPT 算法能解决的问题类称为 BPP（有界错误概率多项式时间）

**密码学中 PPT 的常见用法**：

- 敌手 $\mathcal{A}$ 是 PPT 算法
- 归约算法 $\mathcal{B}$ 也是 PPT 算法（调用 $\mathcal{A}$ 作为子程序）
- 我们说方案是"计算安全的"若任何 PPT 敌手攻破方案的概率可忽略

**Insight**：PPT 是理论和实践之间的桥梁。它足够宽泛以涵盖所有实际可行的攻击，又足够严格以进行数学分析。但需要注意：PPT 是"渐近"分析工具。实际中，一个 $O(2^{n/2})$ 的算法（如生日攻击）是指数级的，但在 $n=128$ 时 $2^{64}$ 次操作可能刚好在可行边界上。渐近分析告诉我们"当 $n$ 增长时安全性如何"，而具体参数选择需要额外考虑。

#### 可忽略函数

函数 $\text{negl}(n)$ 称为可忽略的，如果对任意多项式 $p(n)$，存在 $N$ 使得对所有 $n > N$：

$$\text{negl}(n) < \frac{1}{p(n)}$$

通俗地说：可忽略函数比任何多项式倒数衰减得都快。

**常见例子**：
- $2^{-n}$ 是可忽略的（因为增长比任何多项式快）
- $n^{-\log n}$ 是可忽略的
- $2^{\sqrt{n}}$ 的倒数 $2^{-\sqrt{n}}$ 是**不可忽略**的（因为 $2^{-\sqrt{n}} > 1/2^n$ 对大多数 $n$ 不成立，且存在多项式 $n$ 使得 $2^{-\sqrt{n}} < 1/n$？需要验证... 实际上 $2^{-\sqrt{n}}$ 比任何多项式衰减都快吗？对于 $p(n)=n^{100}$，$2^{-\sqrt{n}} < n^{-100}$ 当 $n$ 足够大时成立，所以它也满足定义——可以证明它也是可忽略的，但比 $2^{-n}$ 衰减慢得多）

**为什么可忽略函数这么定义**：

- 如果敌手成功的概率是可忽略的，那么即使运行多项式次攻击，成功率之和（联合界）仍然可忽略
- 如果成功概率是 $1/n$（不可忽略），运行 $n$ 次攻击后几乎必然成功
- 可忽略性保证了**即使重复攻击也不会有实质威胁**

**Insight**：可忽略函数是"安全参数"设计原则的数学基础。当我说方案是安全的，意思是"成功概率 $\le 2^{-128}$"，这在渐近意义上就是可忽略的。但如果攻击者在 $2^{-30}$ 的概率下能成功，做 $2^{30}$ 次尝试就一定能成功——这显然不安全。可忽略的定义正是为了捕捉"小到什么程度才算真正安全"。

#### 计算不可区分性

两个分布族 $\{X_n\}_{n\in\mathbb{N}}$ 和 $\{Y_n\}_{n\in\mathbb{N}}$ 称为**计算不可区分**的，如果对任意 PPT 区分器 $D$，存在可忽略函数 $\text{negl}(n)$ 使得：

$$|P[D(X_n)=1] - P[D(Y_n)=1]| \le \text{negl}(n)$$

**与统计不可区分的区别**：

- 统计不可区分：区分器无计算能力限制，优势 $\le \text{negl}(n)$
- 计算不可区分：区分器是 PPT，优势 $\le \text{negl}(n)$

显然，统计不可区分 $\Rightarrow$ 计算不可区分，但反之不成立。

**密码学中的核心地位**：

计算不可区分性是整个现代密码学安全定义的基石。几乎所有密码原语的安全性定义都可以归结为：某两个分布的"不可区分性"。

- **伪随机生成器**：PRG 的输出与真随机串计算不可区分
- **伪随机函数**：PRF 与随机函数计算不可区分
- **语义安全**：两个不同明文的密文计算不可区分
- **零知识证明**：模拟视图与真实视图计算不可区分

**Insight**：如果你理解了计算不可区分性，你就理解了现代密码学的大部分。这是一个"以不变应万变"的定义框架——无论安全需求多么复杂，最终几乎都可以规约到"敌手无法区分两个分布"。这正是"多项式时间 + 可忽略优势"这对黄金组合的价值。

#### 单向函数

函数 $f: \{0,1\}^* \to \{0,1\}^*$ 是单向函数，如果：

1. **易计算**：存在 PPT 算法计算 $f$
2. **难求逆**：对任意 PPT 求逆算法 $\mathcal{A}$：
   $$P[\mathcal{A}(f(x), 1^n) \in f^{-1}(f(x))] \le \text{negl}(n)$$
   其中 $x \leftarrow \{0,1\}^n$ 均匀随机

**单向函数的存在性**是密码学的基本假设，是公钥密码存在的必要条件：

- 如果单向函数不存在，则所有加密方案（包括对称加密和公钥加密）都可以被 PPT 敌手攻破
- 几乎所有密码原语的存在性都等价于或蕴含单向函数的存在
- 单向函数是密码学的"最小假设"

**候选单向函数**：
- **大整数乘法**：$f(p,q) = p \times q$ （$p,q$ 为大素数）
- **离散指数**：$f(x) = g^x \pmod{p}$
- **RSA 函数**：$f(x) = x^e \pmod{N}$
- **哈希函数**（理想情况下是单向的）

**单项函数在实践中的体现**：

在密码学系统中，单向函数常用于密钥派生。例如，从密码派生出密钥时，需要使用单向函数（如 PBKDF2）来防止逆向计算。用户密码通常不以明文形式存储，而是存储其单向函数值（哈希值），即使数据库泄露也无法还原密码。

**INSIGHT**：单向函数看似简单，但它实际上蕴含着计算复杂性理论中一个深刻的问题：P ≠ NP 是否足以证明单向函数的存在？目前还不知道答案。单向函数的存在是一个更强的假设，它要求**平均情况下的困难性**，而不仅仅是**最坏情况下的困难性**。这意味着单向函数假设不仅断言某些问题是难解的，还断言在随机实例上也是难解的。这比 P ≠ NP 要强得多。密码学依赖于我们尚未证明但广泛相信的计算复杂性假设。

#### 陷门单向函数

陷门单向函数除了具备单向函数的性质外，还存在一个**陷门（trapdoor）**，使得拥有陷门的人可以高效求逆。

形式化地：函数族 $\{f_{pk}: D_{pk} \to R_{pk}\}_{pk \in \mathcal{PK}}$ 是陷门单向函数，如果：

1. **易计算**：给定 $pk$ 和 $x$，可高效计算 $f_{pk}(x)$
2. **难求逆（无陷门）**：给定 $pk$ 和 $y = f_{pk}(x)$（$x$ 均匀随机），任何 PPT 算法求 $x$ 的概率可忽略
3. **易求逆（有陷门）**：存在 PPT 算法 $\text{Invert}$，给定 $pk$、$y$ 和陷门 $td$，输出 $x$ 使得 $f_{pk}(x) = y$

**密码学价值**：陷门单向函数是公钥密码的数学基础。

- **RSA 陷门**：$f_{N,e}(x) = x^e \bmod N$，陷门是 $d$（私钥指数），满足 $d \cdot e \equiv 1 \pmod{\varphi(N)}$
- **Rabin 陷门**：$f_N(x) = x^2 \bmod N$，陷门是大整数分解 $N = p \times q$

**典型嵌入方式**：

- 公钥加密：加密用 $f_{pk}$，解密用陷门求逆
- 数字签名：签名用陷门求逆（对哈希值），验证用 $f_{pk}$

**Insight**：可以把陷门单向函数想象成一个"单向活板门"——从外面只能进不能出，但如果你拥有钥匙（陷门），就可以从里面出来。公钥密码的本质就是：每个人都有一把锁（公钥），任何人都可以用它锁上消息，但只有拥有钥匙（私钥/陷门）的人才能打开。

**为什么陷门如此难构造**：

- 我们需要一个可以在数学上证明"无陷门不可逆"的函数
- 同时还需要能高效生成这个"陷门"（即密钥生成算法）
- 目前所有候选方案（RSA、ECC、格密码）都是基于特定数学问题的困难性假设，而非证明
- 量子计算机对大部分陷门单向函数构成威胁（Shor 算法可分解大整数、计算离散对数），这也是后量子密码兴起的原因

### 1.4 密码学归约证明

#### 安全归约的基本结构

安全归约的核心思想：**如果存在 PPT 敌手 $\mathcal{A}$ 能攻破密码方案 $\Pi$，那么存在 PPT 算法 $\mathcal{B}$ 能解决某个公认的困难问题 $P$**。

逻辑表述（逆否命题）：

$$\text{如果 } P \text{ 是困难的，那么 } \Pi \text{ 是安全的}$$

**归约的构造方式**：

1. 假设存在 PPT 敌手 $\mathcal{A}$ 以不可忽略概率 $\epsilon$ 攻破 $\Pi$
2. 构造 PPT 算法 $\mathcal{B}$，它利用 $\mathcal{A}$ 作为子程序来解决 $P$
3. 证明如果 $\mathcal{A}$ 成功，则 $\mathcal{B}$ 成功的概率不可忽略
4. 由此得出矛盾（因为 $P$ 被假设为困难的），假设不成立，所以 $\mathcal{A}$ 不存在

**归约的"工作方式"**：

- $\mathcal{B}$ 接收 $P$ 的一个实例（如一个大整数 $N$），需要找到目标值（如 $p,q$）
- $\mathcal{B}$ 为 $\mathcal{A}$ 模拟一个"逼真的"密码方案环境
- $\mathcal{B}$ 必须在不拥有私钥/陷门的情况下，对 $\mathcal{A}$ 的查询给出看似合法的回答
- $\mathcal{A}$ 的输出被 $\mathcal{B}$ 用来提取困难问题的解

**Insight**：归约可以看作是"把敌手变成求解器"。$\mathcal{B}$ 就像是一个中间人：它把困难问题的实例"伪装"成密码方案，诱导敌手帮助它解决问题。归约的质量取决于 $\mathcal{B}$ 模拟环境的"逼真程度"以及成功概率的保持程度。

#### Challenger 与 Adversary

在安全游戏中，通常定义三类角色：

- **Challenger $\mathcal{C}$**：掌控密钥、随机数等秘密，验证敌手的攻击是否成功
- **Adversary $\mathcal{A}$**：试图攻破方案，对 $\mathcal{C}$ 发起查询，最终输出猜测
- **Simulator $\mathcal{B}$**（归约算法）：包装 $\mathcal{A}$，模拟 $\mathcal{C}$ 的角色，同时解决困难问题

**典型的安全游戏流程**（以公钥加密的 IND-CPA 为例）：

1. $\mathcal{C}$ 运行密钥生成算法，得到 $(pk, sk)$，将 $pk$ 给 $\mathcal{A}$
2. $\mathcal{A}$ 选择两条等长消息 $m_0, m_1$
3. $\mathcal{C}$ 随机选择 $b \in \{0,1\}$，加密 $c^* = \text{Enc}_{pk}(m_b)$ 给 $\mathcal{A}$
4. $\mathcal{A}$ 输出猜测 $b'$
5. $\mathcal{A}$ 获胜如果 $b' = b$，且优势定义为 $|\Pr[b' = b] - 1/2|$

**在归约中，$\mathcal{B}$ 扮演 Challenger 角色但嵌入困难问题**：

- $\mathcal{B}$ 不知道 $sk$
- $\mathcal{B}$ 需要在不拥有 $sk$ 的情况下完成游戏
- $\mathcal{A}$ 的输出帮助 $\mathcal{B}$ 计算困难问题的解

**Insight**：Challenger-Adversary 框架是密码学安全证明的标准"戏剧场景"。理解一个安全证明，就是理解 Challenger 如何回答问题、Adversary 如何利用这些回答、以及 Simulator 如何在不知道秘密的情况下"骗过" Adversary。

#### Game-based Proof

基于游戏（Game-Based）的证明方法将安全归约分解为一系列"游戏"（Game），从真实的安全游戏开始，逐步修改，直到最后一个游戏与困难问题直接相关。

每一步修改只引入一个"可忽略的差异"——我们论证敌手无法区分相邻两个游戏。最终，敌手在最后一个游戏中的优势可以归约到某个困难问题。

**典型结构**：

$$G_0 \xrightarrow{\epsilon_1} G_1 \xrightarrow{\epsilon_2} G_2 \xrightarrow{\epsilon_3} \cdots \xrightarrow{\epsilon_k} G_k$$

其中：
- $G_0$：真实的安全游戏
- $G_k$：一个"显然安全"的游戏（如随机猜测）
- 每次修改 $G_i \to G_{i+1}$ 引入的差异 $\le \epsilon_i$
- 总优势 $\le \sum \epsilon_i$（联合界）

**每个 Game Hop 的类型**：

1. **桥接步骤**：改变 Challenger 的行为但不改变分布的统计性质（$\epsilon_i = 0$）
2. **基于困难假设**：如果敌手能区分 $G_i$ 和 $G_{i+1}$，就可以构造区分器解决困难问题
3. **坏事件论证**：$G_i$ 和 $G_{i+1}$ 仅在坏事件发生时不同，而坏事件发生概率可忽略

**经典例子**：ElGamal 加密的 IND-CPA 安全性证明使用 Game-Based 方法，本质上是把 IND-CPA 规约到 DDH 假设。
- $G_0$：真实游戏，$c^* = (g^r, m_b \cdot g^{xr})$
- $G_1$：修改为 $c^* = (g^r, m_b \cdot g^z)$，其中 $z$ 随机
- 区分 $G_0$ 和 $G_1$ 等价于解决 DDH
- $G_1$ 中密文与 $b$ 独立，优势 $= 0$

**Insight**：Game-Based Proof 的核心艺术在于"小步走"。每一步的修改必须足够小，使得（1）我们能证明不可区分性，而且（2）总优势损失仍在可忽略范围内。这就像在冰面上小心翼翼地走，每一步都要确认脚下的冰足够结实，不能一步跨越太远。

#### Hybrid Argument

Hybrid Argument 是 Game-Based Proof 的一个特化技术，用于处理涉及多个副本或块的问题。基本思想是构造 $k+1$ 个"混合分布" $H_0, H_1, \dots, H_k$，使得：

- $H_0$：完全"真实"的分布
- $H_k$：完全"理想"的分布
- $H_i$ 和 $H_{i+1}$ 只在第 $i+1$ 个"元素"上不同

如果区分 $H_i$ 和 $H_{i+1}$ 的优势 $\le \epsilon$，则区分 $H_0$ 和 $H_k$ 的优势 $\le k \cdot \epsilon$（通过三角不等式和混合论证）。

**经典应用**：

- **伪随机函数的安全性**：需要证明 PRF 和真随机函数不可区分。使用 Hybrid Argument 将多查询情况规约到单查询情况
- **伪随机生成器的安全放大**：从短种子扩展输出
- **选择密文安全性**：处理多个解密查询

**Insight**：混合论证利用了"三角不等式"的力量。它把"同时改变 $k$ 件事"的困难问题分解成"一次只改变一件事"的 $k$ 个步骤。虽然最终的界 $k \cdot \epsilon$ 不是紧的（松散因子 $k$），但它给出了一个有效的上界。这个技术之所以强大，是因为它允许我们将"多实例"问题规约到"单实例"问题，从而利用标准困难假设。

**示例**：如果一个 PRG 的扩展因子是 $l(n)$，需要证明它是伪随机的。不用 Hybrid Argument，我们直接需要区分 $l(n)$ 长的 PRG 输出和真随机串——这很复杂。用 Hybrid Argument，我们构造 $l(n)+1$ 个混合，每一步只多一个随机比特，将问题规约到 PRG 的单步安全性。

#### Reduction Loss

Reduction Loss 衡量的是归约的"效率"——即归约中成功的概率保持程度。

设 $\mathcal{A}$ 攻破方案的成功的概率为 $\epsilon_\mathcal{A}$，$\mathcal{B}$ 解决困难问题的概率为 $\epsilon_\mathcal{B}$。如果 $\epsilon_\mathcal{B} \ge \frac{1}{L} \cdot \epsilon_\mathcal{A}$，则称归约有**损失因子** $L$。

**损失来源**：

1. **模拟不完美**：$\mathcal{B}$ 可能无法完美模拟 $\mathcal{A}$ 的环境，导致 $\mathcal{A}$ 在某些情况下失败
2. **猜测代价**：$\mathcal{B}$ 需要猜测 $\mathcal{A}$ 的某些行为（如哪个查询是"关键查询"）
3. **重置/重绕成本**：有些归约需要多次重跑 $\mathcal{A}$
4. **混合论证中的 $k$ 倍因子**：Hybrid Argument 引入与查询数成正比的损失

**影响**：
- 如果 $L$ 很大（如 $L = q^2$，其中 $q$ 是查询数），那么要达到 128 比特安全，底层困难问题需要提供更多比特的安全参数
- 紧归约（$L$ 小）意味着方案更"安全高效"——不需要为了弥补归约损失而增大参数

**Insight**：归约有损失不等于方案不安全。损失因子只是告诉我们"安全参数需要多大"。但这个信息在实践中很重要：如果一个方案只能做到"松散归约"，那就需要用更大的参数来补偿，这会降低效率。这就是为什么密码学界追求"紧归约"——它既为安全性提供了更强保证，也避免了不必要的性能开销。

#### Tight Reduction 与 Loose Reduction

**紧归约（Tight Reduction）**：损失因子 $L$ 是一个小常数（如 1 或 2）。即 $\epsilon_\mathcal{B} \approx \epsilon_\mathcal{A}$。

**松散归约（Loose Reduction）**：损失因子 $L$ 与安全参数或查询数有关（如 $L = q$ 或 $L = q_{H}^2$）。

**为什么紧归约重要**：

- 紧归约意味着方案的安全性和底层困难问题的安全性"直接对应"
- 如果密钥长度为 $k$ 比特的 RSA 提供 $k$ 比特安全，那么基于 RSA 的紧归约方案也提供约 $k$ 比特安全
- 松散归约意味着为了达到同样的安全级别，需要增大参数

**实例**：
- RSA-FDH（Full Domain Hash）签名方案的归约损失为 $q_H$（随机预言机查询数），是典型的松散归约
- 改进的方案（如 RSA-PSS）通过 Probabilistic Signatures 实现更紧的归约

**Insight**：紧归约是"安全论证的质量指标"。一个松散归约的方案不意味着它不安全，而是意味着理论上我们无法证明它和底层假设之间有"紧密"的关系。在实践中，人们仍然使用松散归约的方案（因为底层假设足够强），但紧归约在理论上更令人满意。近年来，密码学界越来越重视紧归约的设计，尤其是对于部署在资源受限环境中的方案。

#### 标准模型与随机预言机模型

**标准模型（Standard Model）**：安全证明中仅基于计算复杂性假设，不依赖任何理想化的对象。敌手的能力只受限于计算时间（PPT），没有额外的限制。

**随机预言机模型（Random Oracle Model, ROM）**：安全证明中将哈希函数理想化为一个"随机预言机"——一个对所有查询返回真正随机值的黑盒函数。敌手只能通过查询来获取函数值，不能分析函数的内部结构。

**标准模型 vs. ROM 的对比**：

| 维度 | 标准模型 | 随机预言机模型 |
|------|-----------|----------------|
| 假设 | 只有标准计算假设 | 计算假设 + ROM 假设 |
| 证明难度 | 更难 | 更容易 |
| 紧致性 | 通常更紧 | 通常松散 |
| 现实性 | 直接对应现实实现 | 需用哈希函数实例化 ROM |
| 安全性 | 更强的理论保证 | ROM 中安全不保证现实安全 |

**著名的 ROM 方案**：
- RSA-FDH 签名
- OAEP 加密填充
- Schnorr 签名
- BLS 签名

**著名的标准模型方案**：
- Cramer-Shoup 加密
- Boneh-Boyen 签名
- Waters 加密（基于配对）

**ROM 的争议**：

Canetti、Goldreich 和 Halevi 构造了 ROM 中可证明安全但在任何实例化下都不安全的"反例"方案。这说明 ROM 安全性不蕴含标准模型安全性。

**但为什么 ROM 仍然被广泛使用**：

- 大多数 ROM 反例是人为构造的，没有实际意义
- 对于许多实际方案，ROM 是目前唯一可行的证明方法
- ROM 证明至少排除了对方案的"结构性攻击"（只依赖哈希函数的随机性）
- 在实践中，ROM 证明的方案被广泛使用且没有因 ROM 缺陷被攻破

**Insight**：标准模型和 ROM 的选择类似于"纯数学"和"应用数学"的区别。标准模型追求理论上的严谨性，ROM 追求实用性和可证明性。作为一个密码学研究者，应当理解两者各自的优缺点，并根据场景选择合适的方法——设计核心基础设施时倾向标准模型，构建高效实用方案时 ROM 完全可接受。

## 第2章 代数与数论基础

### 2.1 模运算

#### 同余关系

给定正整数 $n$，称 $a$ 与 $b$ 模 $n$ 同余，记作 $a \equiv b \pmod{n}$，如果 $n \mid (a - b)$。

同余是一个**等价关系**（自反、对称、传递），它将整数划分为 $n$ 个等价类（剩余类）：$[0], [1], \dots, [n-1]$。

**同余的基本性质**：

- $a \equiv b \pmod{n}$ 且 $c \equiv d \pmod{n}$ $\Rightarrow$ $a \pm c \equiv b \pm d \pmod{n}$，$ac \equiv bd \pmod{n}$
- **除法不是自由操作**：$ac \equiv bc \pmod{n}$ 不意味着 $a \equiv b \pmod{n}$，除非 $\gcd(c,n) = 1$

**密码学意义**：所有现代密码学中的运算都是模运算。原因在于：

1. **有限性**：计算机不能处理无限大的整数，模运算把数字限制在有限范围内
2. **安全性**：模运算引入了"环绕"效果，使逆向运算困难
3. **效率**：模运算在计算机中通过有限字长的整数运算高效实现

**Insight**：同余关系的核心洞察是"把无限映射到有限"。密码学中的整数操作永远在有限环 $\mathbb{Z}_n$ 中进行，这种"回绕"是很多安全属性的来源。例如，RSA 中利用的是模 $\varphi(N)$ 的指数运算的周期性。

#### 模逆

$a$ 的模逆是满足 $a \cdot a^{-1} \equiv 1 \pmod{n}$ 的整数 $a^{-1}$。模逆存在当且仅当 $\gcd(a,n) = 1$。

**为什么模逆存在需要互素条件**：
- $a \cdot x \equiv 1 \pmod{n}$ 等价于存在整数 $k$ 使得 $a \cdot x + n \cdot k = 1$
- 根据 Bezout 定理，方程有解当且仅当 $\gcd(a,n) = 1$

**密码学应用**：
- **RSA 解密**：$d \cdot e \equiv 1 \pmod{\varphi(N)}$，私钥 $d$ 是公钥 $e$ 模 $\varphi(N)$ 的逆
- **ElGamal 解密**：计算 $c_2 \cdot (c_1^x)^{-1} \pmod{p}$，需要求 $(c_1^x)^{-1}$
- **秘密共享**：Lagrange 插值中需要计算模逆

**Insight**：模逆是现代密码学"非对称性"的核心。你有私钥（知道一些秘密信息）就可以计算模逆，但别人不能。RSA 的安全性归根结底就是：没有 $\varphi(N)$ 你就无法高效计算 $e$ 的模逆。

#### 欧几里得算法

欧几里得算法用于计算两个整数的最大公约数 $\gcd(a,b)$：

- $\gcd(a,b) = \gcd(b, a \bmod b)$
- 重复应用直到余数为 0，最后的非零余数即为 $\gcd$

**算法复杂度**：$O(\log \min(a,b))$ 次除法——非常高效。

**密码学中用于**：
- 检查两个数是否互素（如密钥生成时检查 $e$ 和 $\varphi(N)$ 互素）
- 在 RSA 密钥生成和拉宾密码系统中用于确定参数可行性

#### 扩展欧几里得算法

扩展欧几里得算法不仅计算 $\gcd(a,b)$，还找到 Bezout 系数 $x,y$ 满足：

$$a \cdot x + b \cdot y = \gcd(a,b)$$

**密码学核心应用——计算模逆**：
- 要计算 $a^{-1} \pmod{n}$，在扩展欧几里得算法中输入 $(a,n)$
- 得到 $a \cdot x + n \cdot y = 1$，则 $x \equiv a^{-1} \pmod{n}$

**算法原理**：
1. 递归计算 $\gcd(a,b)$ 的同时跟踪系数
2. 当 $b=0$ 时返回 $(a, 1, 0)$
3. 否则递归计算 $(d, x', y') = \text{ExtendedEuclid}(b, a \bmod b)$
4. 返回 $(d, y', x' - \lfloor a/b \rfloor \cdot y')$

**密码学场景**：
- RSA 密钥生成中计算 $d \equiv e^{-1} \pmod{\varphi(N)}$
- ECC 中标量乘法中涉及模逆运算
- 中国剩余定理实现中需要计算模逆

**Insight**：扩展欧几里得算法是密码学工具箱中最基础的算法之一。每次你生成 RSA 密钥对、每次你在 $\mathbb{Z}_p$ 中做除法、每次你用 CRT 加速解密——背后都有扩展欧几里得算法在运行。它虽简单但不可或缺，就像螺丝刀在机械工具箱中的地位。

#### 中国剩余定理

**中国剩余定理（CRT）**：设 $n_1, n_2, \dots, n_k$ 两两互素，$n = \prod_{i=1}^k n_i$。则同余方程组：

$$x \equiv a_1 \pmod{n_1}$$
$$x \equiv a_2 \pmod{n_2}$$
$$\vdots$$
$$x \equiv a_k \pmod{n_k}$$

在模 $n$ 下有唯一解。

**构造性解**：
$$x \equiv \sum_{i=1}^k a_i \cdot N_i \cdot N_i^{-1} \pmod{n}$$
其中 $N_i = n / n_i$，$N_i^{-1}$ 是 $N_i$ 模 $n_i$ 的逆。

**CRT 的两种密码学用法**：

1. **RSA 解密加速**：
   - 私钥操作原本在模 $N = p \cdot q$ 下进行
   - CRT 允许在模 $p$ 和模 $q$ 下分别计算再组合
   - 加速约 4 倍（因为 $p,q$ 约 $\sqrt{N}$，模乘复杂度是 $O(\log^2 N)$，两个模 $\sqrt{N}$ 的操作总复杂度减半，加上 CRT 组合的线性成本）

2. **秘密共享（Shamir 方案）**：
   - 秘密 $s$ 被编码为 $f(0)$，其中 $f$ 是 $t-1$ 次多项式
   - 分享 $f(i) \bmod p$ 给参与者 $i$
   - 任意 $t$ 个参与者可用 Lagrange 插值（本质上是 CRT 的推广）恢复 $s$

**Insight**：CRT 告诉我们可以"分而治之"地处理大模数运算。在密码学中，大数运算是性能瓶颈，而 CRT 提供了一种天然的并行化/加速方法。它本质上是利用了不同模数的独立性，把一个大问题拆成几个小问题，再把答案组合起来。CRT 还告诉我们"模 $n$ 下的数"和"模各个素因子的元组"之间存在一一对应——即 $\mathbb{Z}_n \cong \mathbb{Z}_{p_1} \times \mathbb{Z}_{p_2} \times \cdots$。

### 2.2 群、环与域

#### 群和循环群

**群** $(G, \cdot)$ 是一个集合 $G$ 和二元运算 $\cdot$，满足封闭性、结合律、存在单位元、每个元素有逆元。

**密码学中最常用的群**：

1. **整数模 $n$ 的加法群** $(\mathbb{Z}_n, +)$：
   - 单位元：$0$
   - $a$ 的逆元：$-a \bmod n$
   - 平凡地是循环群（生成元：$1$）

2. **模 $p$ 的乘法群** $(\mathbb{Z}_p^*, \cdot)$：
   - 元素：$\{1, 2, \dots, p-1\}$
   - 单位元：$1$
   - $a$ 的逆元：$a^{p-2} \bmod p$（费马小定理）
   - 群阶：$p-1$
   - 是循环群（存在生成元 $g$）

**循环群**：存在一个元素 $g$（生成元）使得群中每个元素都可以写成 $g^k$ 的形式。

- $(\mathbb{Z}_p^*, \cdot)$ 是循环群——这是离散对数密码学的基础
- $(\mathbb{Z}_n, +)$ 总是循环群
- 椭圆曲线上的点构成加法群（通常是循环群或接近循环群）

**密码学中的群选择原则**：
- 群运算必须高效计算
- 群中离散对数问题必须困难
- 群阶必须有已知的大素因子（防止 Pohlig-Hellman 攻击）

**Insight**：密码学选择群的核心矛盾是"运算效率 vs 安全强度"。群越大越安全但越慢，群太小快但不安全。此外，群的结构性也很重要——循环群结构简单，恰好满足 Diffie-Hellman 密钥交换的需求。ECC 通过使用椭圆曲线群，在同样安全强度下比 $\mathbb{Z}_p^*$ 群更高效（256 比特的 ECC ≈ 3072 比特的 RSA）。

#### 子群和群阶

**子群**：群 $G$ 的子集 $H$ 如果在 $G$ 的运算下构成群，称为 $G$ 的子群。

**群阶**：群中元素的个数，记作 $|G|$ 或 $\text{ord}(G)$。

**元素的阶**：使 $a^m = e$ 的最小正整数 $m$。

**Lagrange 定理**：子群的阶整除群阶。因此元素的阶也整除群阶。

**密码学意义**：

- 在 $\mathbb{Z}_p^*$ 中，通常使用素数阶子群而不是整个 $p-1$ 阶群
- 因为素阶子群没有非平凡子群，可以抵抗 Pohlig-Hellman 攻击
- 通常取 $p = 2q + 1$（安全素数），使用 $q$ 阶子群

**子群攻击**：如果群阶有小素因子 $r$，敌手可以在 $O(\sqrt{r})$ 时间内计算离散对数到该子群。这就是为什么大整数分解和离散对数密码学中要使用具有大素因子的群。

**Insight**：群阶是密码学安全性的"第一道防线"。群阶太小不行（穷举可行），群阶有太多小因子也不行（Pohlig-Hellman 分解攻击）。实际上，"素阶群"往往是密码学家的最爱——因为子群结构最简单，攻击面最小。大多数密码学标准都选用素阶群。

#### 生成元

生成元 $g$ 是满足 $G = \{g^0, g^1, \dots, g^{|G|-1}\}$ 的元素。循环群不一定只有一个生成元。

**生成元的个数**：在 $n$ 阶循环群中，生成元的个数是 $\varphi(n)$（Euler 函数）。

**如何找到生成元**：
- 对于 $\mathbb{Z}_p^*$，检查 $g^{(p-1)/q} \not\equiv 1 \pmod{p}$ 对所有 $p-1$ 的素因子 $q$ 成立
- 实践中，常使用一个已知生成元 $g$ 的素数阶子群

**密码学应用**：
- Diffie-Hellman 密钥交换需要双方共享一个生成元 $g$
- ElGamal 加密和签名都需要 $g$ 作为系统参数
- 离散对数困难性要求 $g$ 确实是生成元

**关于"生成元"的直觉**：

在循环群中，生成元就像是"源头泉水"——从它出发的任何指数运算都能到达群中任何一个元素。没有生成元，我们这个群就"无从开始"。在 Diffie-Hellman 中，如果 $g$ 不是生成元而是某个子群的生成元，安全级别会降低。

**Insight**：生成元的选取有时被忽视，但实际上影响安全。如果 $g$ 生成的子群阶有小的素因子，安全性直接打折扣。标准的密码库（如 OpenSSL）会正确处理这一点，但定制实现时常出错。另外，生成元可以公开，公钥 $g^x$ 也是公开的——安全性完全依赖于 $x$ 的秘密性，这和"一切秘密在密钥中"的 Kerckhoffs 原则一致。

#### 环与理想

**环** $(R, +, \cdot)$ 是有两个二元运算的代数结构：
- $(R, +)$ 是阿贝尔群（单位元 $0$）
- $(R, \cdot)$ 是半群（封闭、结合）
- 分配律：$a \cdot (b+c) = a\cdot b + a\cdot c$，$(a+b)\cdot c = a\cdot c + b\cdot c$

**常见环**：
- 整数环 $(\mathbb{Z}, +, \cdot)$
- 模 $n$ 的剩余类环 $(\mathbb{Z}_n, +, \cdot)$
- 多项式环 $R[x]$

**理想**：环 $R$ 的子集 $I$ 是理想，如果：
- $(I, +)$ 是 $(R, +)$ 的子群
- 对任意 $r \in R$ 和 $a \in I$，$r \cdot a \in I$（吸收性质）

**主理想**：由一个元素生成的理想 $(a) = \{r \cdot a \mid r \in R\}$

**密码学意义**：
- $\mathbb{Z}_n$ 是环但不是域（当 $n$ 不是素数时，非零元素不一定有乘法逆）
- 理想理论是格密码的基础
- 商环 $\mathbb{Z}_n = \mathbb{Z}/(n)$ 是同余关系的代数观点——我们把所有差为 $n$ 倍数的整数"归为一类"

**Insight**：环和域的区别在于：在环中不一定能做除法（找乘法逆），但在域中可以做。公钥密码学要求工作在一个域（如 $\mathbb{F}_p$ 或 $\mathbb{F}_{2^n}$）或特殊环（如 $\mathbb{Z}_N$ 对知道分解的人而言是"伪域"）中。如果你尝试在环 $\mathbb{Z}_n$ 中做 ElGamal（其中 $n$ 不是素数），大部分元素没有逆，加解密可能失败——这就是为什么密码学计算总是在有限域中进行的本质原因。

#### 有限域

**域** $(F, +, \cdot)$ 是一个交换环且每个非零元素都有乘法逆。

**有限域**：元素个数有限的域。有限域的阶必为 $p^k$ 形式（$p$ 为素数），记作 $\mathbb{F}_{p^k}$。

**两类常用有限域**：

1. **素域 $\mathbb{F}_p$**：$p$ 为大素数，元素为 $\{0,1,\dots,p-1\}$，运算模 $p$
   - 用于 RSA、DSA、ElGamal
   
2. **二元扩域 $\mathbb{F}_{2^n}$**：元素是 $n-1$ 次多项式，系数在 $\mathbb{F}_2$ 中
   - 用于 AES（$\mathbb{F}_{2^8}$）、ECC（某些曲线）、纠错码

**有限域的特性**：
- 特征为 $p$（$p \cdot 1 = 0$）
- 乘法群 $\mathbb{F}_{p^k}^*$ 是 $p^k-1$ 阶循环群
- $\mathbb{F}_{p^k}$ 是 $\mathbb{F}_p$ 的 $k$ 次扩域

**密码学选择有限域的原则**：
- 素域 $\mathbb{F}_p$ 对软件实现友好（CPU 原生支持大整数模运算）
- 二元扩域 $\mathbb{F}_{2^n}$ 对硬件实现友好（移位和 XOR）
- 安全性取决于离散对数问题在 $\mathbb{F}_{p^k}$ 上的难度

**Insight**：有限域是密码学中"安全计算"的基础。有了有限域理论，我们才能在计算机的有限字长下实现安全的数学运算。$\mathbb{F}_p$ 就像是一个"循环的世界"——加法和乘法都在这个有限的世界中封闭地运行，不会溢出到无限大。AES 中对 $\mathbb{F}_{2^8}$ 的选择也不是偶然：8 比特的域元素恰好对应一个字节，运算可以通过查表和 XOR 高效实现。

#### 多项式环

多项式环 $R[x]$ 是以 $R$ 中元素为系数的多项式的集合，加法和乘法按通常方式定义。

**密码学作用**：

1. **有限域的构造**：$\mathbb{F}_{p^k} \cong \mathbb{F}_p[x]/(f(x))$，其中 $f(x)$ 是 $k$ 次不可约多项式
2. **格密码的基础**：环-LWE（Ring-LWE）在多项式环 $\mathbb{Z}_q[x]/(f(x))$ 上定义
3. **CRC 和纠错码**：多项式环是循环码的基础
4. **NTRU 加密**：在截断多项式环 $\mathbb{Z}_q[x]/(x^N - 1)$ 上工作

**不可约多项式**在密码学中的重要性：就像素数在整数环中一样，不可约多项式在多项式环中是"不可分解的原子"。我们需要不可约多项式来构造域（就像我们需要素数来构造 $\mathbb{Z}_p$）。

**Insight**：理解多项式环的结构对于理解后量子密码至关重要。目前最热门的后量子密码方案（Kyber、Dilithium、FALCON）都基于格/环-LWE 问题，而这些问题恰恰定义在多项式环上。如果你熟悉 $\mathbb{Z}_q[x]/(x^n+1)$ 上的运算，你就掌握了大多数后量子密码方案的数学基础。

#### 商环

商环 $R/I$ 是由模理想 $I$ 的等价类构成的环。构造方法：
1. 定义等价关系：$a \sim b$ 如果 $a - b \in I$
2. 等价类集合 $R/I$ 在自然诱导的运算下构成环

**最重要的密码学例子**：
- $\mathbb{Z}_n = \mathbb{Z}/(n)$：整数模 $n$ 的环
- $\mathbb{F}_{p^k} = \mathbb{F}_p[x]/(f(x))$：有限域
- $\mathbb{Z}_q[x]/(x^n+1)$：环-LWE 的工作环境

**商环为什么是密码学的基本工具**：

密码学的核心运算是模运算，而模运算恰好就是商环中的运算。当你计算 $a \bmod n$ 时，你实际上在做 $\mathbb{Z} \to \mathbb{Z}/(n)$ 的自然投影。

**Insight**：商环提供了"模"概念的代数框架。你取一个大的代数结构（如 $\mathbb{Z}[x]$），然后"模掉"一个关系（如 $x^n+1=0$），得到一个新的、更小的结构。这正是密码学中"约束带来安全性"的哲学体现——我们主动限制运算空间以获得理想的数学性质。

### 2.3 经典困难问题

#### 大整数分解问题

**问题描述**：给定大合数 $N = p \cdot q$（$p,q$ 为大素数），求 $p$ 和 $q$。

**整数分解假设**：任何 PPT 算法分解随机生成的 RSA 模数 $N$ 的概率是可忽略的。

**著名的分解算法及其复杂度**：
- 试除法：$O(\sqrt{N})$ — 对 $N > 2^{256}$ 完全不现实
- Pollard's Rho：$O(N^{1/4})$ — 中等规模有效
- Quadratic Sieve：$L_N[1/2, 1]$ — 通用算法
- 数域筛法（NFS）：$L_N[1/3, (64/9)^{1/3}]$ — 最好的通用算法
  $$L_N[\alpha, c] = \exp((c + o(1)) (\ln N)^\alpha (\ln \ln N)^{1-\alpha})$$

**目前分解记录**：RSA-250（829 比特，2020 年分解，约 2700 核年）

**密码学地位**：大整数分解假设是 RSA 密码系统、Rabin 密码系统、Goldwasser-Micali 密码系统的基础。

**Insight**：分解的难度来源于"乘法容易，分解困难"的非对称性——这是最经典的"单向性"例子。量子计算机上，Shor 算法可以在 $O((\log N)^3)$ 时间内分解整数，这是后量子密码发展的核心驱动力。值得注意的是，大部分人认为 RSA-2048（617 位十进制数）在当前经典计算机下是安全的，但没人能严格证明分解是困难的——它只是被广泛相信是困难的。

#### 离散对数问题

**问题描述**：给定循环群 $G$、生成元 $g$ 和元素 $h = g^x$，求 $x$。

**离散对数假设**：在特定群族（如 $\mathbb{Z}_p^*$ 或椭圆曲线群）上，任何 PPT 算法计算离散对数的概率可忽略。

**影响难度的因素**：
- **群的表示**：$\mathbb{Z}_p^*$ 中有次指数算法（Index Calculus），椭圆曲线群中无
- **群阶的大小**：阶越大越难
- **群阶的最大素因子**：Pohlig-Hellman 攻击将问题规约到各素因子子群

**密码学应用**：
- Diffie-Hellman 密钥交换的安全性
- ElGamal 加密和签名
- DSA（数字签名算法）
- Schnorr 签名

**常见群的安全参数**：
- $\mathbb{Z}_p^*$：$p$ 至少 2048 比特
- ECC 群：群阶约 256 比特即可达到类似安全级别

**Insight**：离散对数问题和整数分解问题在结构上有深刻联系。事实上，如果离散对数在 $\mathbb{Z}_p^*$ 中可解，则分解也可以；但反之不一定成立。椭圆曲线离散对数（ECDLP）是目前认为最困难的离散对数问题之一——这也是 ECC 能以更短密钥达到相同安全强度的原因。Index Calculus 不能在 ECC 上工作，因为没有自然的"平滑性"概念。

#### 计算型 Diffie–Hellman 问题

**CDH 问题**：给定 $(g, g^a, g^b)$，计算 $g^{ab}$。

**CDH 假设**：任何 PPT 算法解决 CDH 的概率可忽略。

**CDH 与离散对数的关系**：
- 解决离散对数 $\Rightarrow$ 解决 CDH（先求 $a$ 再算 $g^{ab} = (g^b)^a$）
- 反之是否成立？**不确定**——CDH 可能比离散对数容易，也可能一样难
- 在大多数密码学使用的群中，CDH 和离散对数被假设为等难的

**密码学应用**：
- Diffie-Hellman 密钥交换的本质安全需求
- ElGamal 加密的解密等价于解决 CDH
- 许多两方/三方协议的安全性基于 CDH

**Insight**：CDH 是"半计算性"假设——我们要求敌手算出一个具体值（$g^{ab}$），而不是区分两个分布。在安全归约中，CDH 通常比 DDH 更容易假设（因为 DDH 更强），所以尽量用 CDH 假设来证明方案是更保守的选择。ElGamal 加密的 IND-CPA 安全性实际上需要 DDH，但其单向性只依赖 CDH。

#### 判定型 Diffie–Hellman 问题

**DDH 问题**：区分两个分布：
- $(g, g^a, g^b, g^{ab})$ — "真" DH 元组
- $(g, g^a, g^b, g^c)$ — 随机元组，其中 $c$ 随机

**DDH 假设**：这两个分布是计算不可区分的。

**DDH 与 CDH 的关系**：
- 解决 CDH $\Rightarrow$ 解决 DDH（计算 $g^{ab}$ 并与 $g^c$ 比较）
- 反之不一定成立——DDH 是比 CDH 更强的假设（更难满足）

**DDH 在哪些群中成立**：
- 在 $\mathbb{Z}_p^*$ 中，**DDH 不成立**：可以利用 Legendre 符号区分 $g^{ab}$ 和随机元素
- 在 $\mathbb{Z}_p^*$ 的素数阶子群中，DDH 被认为成立
- 在椭圆曲线群中，DDH 通常成立
- 在双线性配对群中，DDH 在源群中成立但在目标群中不成立

**密码学应用**：
- ElGamal 加密的 IND-CPA 安全性
- ElGamal 的变体用于 CCA 安全加密
- 许多基于 DDH 的协议（如 Naor-Reingold PRF）
- DDH 在"判定性"归约中非常有用

**Insight**：DDH 之所以如此强大，是因为它允许我们直接将明文"隐藏"在 Diffie-Hellman 共享秘密中。在 ElGamal 中，如果 DDH 成立，密文 $(g^r, m \cdot g^{xr})$ 中的 $g^{xr}$ 看起来就像随机元素，完美地隐藏了 $m$。DDH 是"结构化随机性"的完美体现——看上去随机的 $g^{ab}$ 实际上具有代数结构（因为 $a,b$ 关联着 $g^a,g^b$）。

#### RSA 问题

**RSA 问题**：给定 RSA 公钥 $(N, e)$ 和密文 $c = m^e \bmod N$，求 $m$。

**RSA 假设**：任何 PPT 算法解决 RSA 问题的概率可忽略。

**RSA 问题与分解的关系**：
- 分解 $N$ $\Rightarrow$ 解决 RSA 问题（计算 $\varphi(N) = (p-1)(q-1)$，求 $d = e^{-1} \bmod \varphi(N)$，计算 $m = c^d \bmod N$）
- 反之是否成立？**不知道**——可能存在解决 RSA 问题但不分解 $N$ 的方法
- RSA 假设比分解假设更强（即 RSA 假设蕴含分解假设的否定）

**RSA 的数学结构**：
- $\mathbb{Z}_N^*$ 是 $N = pq$ 上的乘法群，阶为 $\varphi(N) = (p-1)(q-1)$
- 函数 $f(x) = x^e \bmod N$ 是 $\mathbb{Z}_N^*$ 到自身的双射（当 $\gcd(e, \varphi(N)) = 1$）
- 其逆函数是 $f^{-1}(x) = x^d \bmod N$

**常见攻击**：
- 小 $e$ 攻击（Coppersmith）：当明文太短时可通过求小整数根恢复
- 共模攻击：同一明文对两个互素指数加密可恢复明文
- 低解密指数攻击（Wiener）：$d < N^{1/4}$ 时可被连分数攻击恢复
- 选择密文攻击：RSA 是乘法同态的，$E(m_1)E(m_2) \equiv E(m_1m_2)$，可被利用

**Insight**：RSA 问题是最早被系统研究的密码学困难问题之一。它的优雅在于数学结构极其简单——就是指数运算在 $\mathbb{Z}_N$ 中的单向性。但 RSA 的简单结构也导致了许多陷阱：
- 确定性加密 $\Rightarrow$ IND-CPA 不安全
- 乘法同态性 $\Rightarrow$ 需要 OAEP 填充实现 CCA 安全
- 明文的小范围 $\Rightarrow$ 需要足够大的填充

RSA 的安全性依赖于"$\mathbb{Z}_N$ 上的 $e$ 次根难求"这个假设。这个假设在 40 多年的密码分析中仍然站稳脚跟（虽然参数要求变大了）。

#### 二次剩余问题

**二次剩余定义**：$a \in \mathbb{Z}_n^*$ 是模 $n$ 的二次剩余，如果存在 $x$ 使得 $x^2 \equiv a \pmod{n}$。记 $QR_n$ 为二次剩余集合。

**二次剩余判定**：
- 模素数 $p$：使用 Euler 准则 $a^{(p-1)/2} \equiv \left(\frac{a}{p}\right) \pmod{p}$，若结果为 1 则是二次剩余，-1 则不是
- 模合数 $N = pq$：$a$ 是二次剩余当且仅当 $a$ 同时是模 $p$ 和模 $q$ 的二次剩余

**二次剩余问题（QR 问题）**：给定合数 $N = pq$ 和 $a \in \mathbb{Z}_N^*$，判断 $a$ 是否为模 $N$ 的二次剩余。

**QR 假设**：如果不知道 $p,q$，任何 PPT 算法正确判定二次剩余的概率不可忽略地优于 $1/2$。

**与分解的关系**：
- 分解 $N$ $\Rightarrow$ 解决 QR 问题
- 反之？不知道——QR 问题可能比分解容易
- 在 Blum 整数（$p \equiv q \equiv 3 \pmod{4}$）下，QR 问题被认为和分解等价

**密码学应用**：
- **Goldwasser-Micali 加密**：第一个被证明是语义安全的公钥加密方案
  - 密文每比特是一个 $\mathbb{Z}_N^*$ 元素
  - 0：加密为随机二次剩余
  - 1：加密为随机非二次剩余
  - 安全性直接基于 QR 假设
- **Blum-Blum-Shub 伪随机生成器**：利用 QR 和平方运算的安全性

**Insight**：QR 问题在密码学历史中扮演了特殊的角色——它是第一个被用来实现语义安全加密的困难问题（GM 加密，1982）。虽然 GM 加密效率极低（1 比特/$N$ 比特），但它开创了"基于可证明安全"的加密设计范式。QR 问题的本质是"判断平方根的存在性，但不需要找到平方根"——这正是判定性问题的特征。

### 2.4 椭圆曲线基础

#### 椭圆曲线群

椭圆曲线 $E$ 在域 $\mathbb{F}_p$ 上定义为方程：

$$y^2 = x^3 + ax + b$$

其中 $4a^3 + 27b^2 \not\equiv 0 \pmod{p}$（保证曲线非奇异，即没有尖点和自交点）。

**椭圆曲线上的群结构**：

- 元素：曲线上的点 $(x,y)$ 加上一个额外元素——无穷远点 $\mathcal{O}$（单位元）
- 群运算：点加法，"弦切线法则"
- **封闭性**：曲线上两点相加得到曲线上的第三点
- 单位元：$\mathcal{O}$
- 逆元：$(x,y)$ 的逆是 $(x, -y)$

**群阶**：$E(\mathbb{F}_p)$ 中点的数量约为 $p + 1 \pm 2\sqrt{p}$（Hasse 定理）。

**Insight**：椭圆曲线群的奇妙之处在于其"加法"规则不是直观的坐标加法，而是通过几何构造（过两点的直线与曲线的交点）定义的。这种非传统的群运算恰好具有所有群公理，而且其结构"足够随机"——没有 Index Calculus 攻击可以利用的平滑性概念。这是 ECC 能提供更高安全强度的根本原因。

#### 点加法与倍点运算

**点加法** ($P + Q = R$)：
- 如果 $P \neq \pm Q$：过 $P$ 和 $Q$ 的直线交曲线于第三点 $R'$，$R$ 是 $R'$ 的 $x$ 轴对称点
- 如果 $P = Q$（倍点）：过 $P$ 的切线与曲线的交点关于 $x$ 轴对称
- 如果 $P = -Q$：$P + Q = \mathcal{O}$
- 如果 $P = \mathcal{O}$：$\mathcal{O} + Q = Q$

**代数表达式**（在 $\mathbb{F}_p$ 上，$P = (x_1, y_1)$, $Q = (x_2, y_2)$）：

当 $P \neq \pm Q$：
$$\lambda = \frac{y_2 - y_1}{x_2 - x_1} \pmod{p}$$
$$x_3 = \lambda^2 - x_1 - x_2 \pmod{p}$$
$$y_3 = \lambda(x_1 - x_3) - y_1 \pmod{p}$$

当 $P = Q$（倍点）：
$$\lambda = \frac{3x_1^2 + a}{2y_1} \pmod{p}$$
$$x_3 = \lambda^2 - 2x_1 \pmod{p}$$
$$y_3 = \lambda(x_1 - x_3) - y_1 \pmod{p}$$

**标量乘法**（$kP$ 表示 $P$ 自加 $k$ 次）：
- 使用**双倍加算法**（Double-and-Add）：将 $k$ 转为二进制，对每个比特做倍点和（若比特为 1）加法
- 复杂度：$O(\log k)$ 次倍点和 $O(\log k)$ 次点加
- 是 ECDLP 中的"单向操作"——正向计算容易，逆向（已知 $kP$ 和 $P$ 求 $k$）困难

**Insight**：标量乘法 $kP$ 是 ECC 的核心计算，类似于 $\mathbb{Z}_p^*$ 中的模幂 $g^k$。但椭圆曲线的标量乘法没有类似 Index Calculus 的攻击方法。理解 Double-and-Add 算法很重要：它告诉我们标量乘法的计算量与被乘数的比特长度成正比，这就是为什么 256 比特的 ECC 是实用的——256 次倍点和约 128 次加法 ≈ 384 次群运算。

#### 椭圆曲线离散对数问题

**ECDLP**：给定椭圆曲线 $E(\mathbb{F}_p)$ 上的两个点 $P$ 和 $Q = kP$，求 $k$。

**已知最好的攻击**：
- Pollard's Rho：$O(\sqrt{n})$ 时间，其中 $n$ 是群阶的最大素因子
- Pohlig-Hellman：将问题规约到各素因子子群
- **没有**类似 Index Calculus 的亚指数算法（对于一般椭圆曲线）

**为什么 ECDLP 比 $\mathbb{Z}_p^*$ 中的 DLP 更难**：
- $\mathbb{Z}_p^*$ 中存在 Index Calculus：利用"平滑"元素分解
- 椭圆曲线群中缺少"平滑"概念和自然的嵌入到环中的方法
- 这意味着对于同样的安全强度，ECC 需要的密钥长度远小于基于 $\mathbb{Z}_p^*$ 的方案

**安全强度对比**：

| 安全级别 | RSA/$\mathbb{Z}_p^*$ 长度 | ECC 长度 |
|----------|--------------------------|----------|
| 80 比特 | 1024 比特 | 160-192 比特 |
| 112 比特 | 2048 比特 | 224 比特 |
| 128 比特 | 3072 比特 | 256 比特 |
| 256 比特 | 15360 比特 | 512 比特 |

**Insight**：ECDLP 的困难性是现代密码学中最有价值的"非对称性"之一。224 比特的 ECC 和 2048 比特的 RSA 提供的安全强度差不多，但 ECC 的密钥更短、运算更快、存储更少。这在移动设备和 IoT 设备上优势明显。需要注意的是，**并非所有椭圆曲线都安全**——某些特殊曲线（如超奇异曲线、反常曲线）上的 ECDLP 可以被高效求解。

#### ECC 相对于传统 RSA 的特点

| 比较维度 | ECC | RSA |
|----------|-----|-----|
| 密钥长度 | 短（256 比特） | 长（3072 比特） |
| 运算速度 | 较快（私钥操作更快） | 较慢 |
| 签名长度 | 短（64 字节） | 长（512 字节） |
| 密钥生成 | 快 | 慢（需要生成大素数） |
| 数学基础 | ECDLP | 大整数分解 |
| 量子抵抗 | 否（都被 Shor 算法威胁）| 否 |
| 标准支持 | 逐渐完善 | 非常成熟 |

**ECC 的优势场景**：
- 移动设备、智能卡等资源受限环境
- 需要快速握手和短签名的协议（如 TLS 1.3 广泛使用 ECDHE）
- 区块链和数字签名（比特币使用 secp256k1）

**RSA 的优势场景**：
- 旧的兼容性要求
- 加密操作比解密多（RSA 公钥操作快，加密用 $e=65537$ 很快）
- 简单理解（更多人理解 RSA 而非 ECC）

**Insight**：ECC 的主要优势不是"安全性更强"，而是"同样安全性下效率更高"。但这个高效率带来了一些实际问题：ECC 的安全参数选择更微妙——曲线的选取直接影响安全性（如 Curve25519 vs. NIST P-256 vs. secp256k1），而 RSA 的参数选择更直接（只需选择 $N$ 的比特长度）。ECC 的正确实现也更容易出错（如无效曲线攻击、侧信道）。这些"可用性"问题使一些开发者倾向于 RSA。

#### 曲线参数与安全性

**标准曲线参数**（以 secp256k1 为例）：
- $p$：定义域的特征（素数）
- $a, b$：曲线方程的系数（$y^2 = x^3 + ax + b$）
- $G$：基点（生成元）
- $n$：基点的阶（素数）
- $h$：余因子（$h = |E|/n$，通常为 1）

**安全曲线的要求**：

1. **素数阶或近素数阶**：$n$ 是大素数，确保没有小阶子群
2. **非超奇异**：超奇异曲线的嵌入度低，MOV 攻击可将 ECDLP 归约到有限域 DLP
3. **CM 抵抗**：防止 Weil/Tate Pairing 攻击
4. **无异常**：$|E(\mathbb{F}_p)| \neq p$（否则 Smart 攻击可解 ECDLP）
5. **扭曲安全**：抵抗无效曲线攻击（如 Curve25519 特意设计来抵抗此类攻击）

**流行曲线的安全性比较**：

- **Curve25519（X25519）**：
  - 由 Daniel Bernstein 设计（高安全性、高速度）
  - $y^2 = x^3 + 486662x^2 + x$（Montgomery 形式）
  - 设计避免了许多实现陷阱（常数时间、无专利）
  - TLS 1.3 中的首选曲线
  
- **NIST P-256（secp256r1）**：
  - 广泛使用、广泛支持
  - 参数由 NIST 通过 SHA-1 生成（消除"可疑参数"的疑虑）
  - 不是 twist-secure（需要实现验证）

- **secp256k1**：
  - 比特币选择的曲线
  - $a = 0$，$b = 7$ —— 参数简单，更透明
  - 非 NIST 曲线（避免 NIST 后门疑虑）

**Insight**：曲线选择是密码学中"安全参数"最微妙的地方。不同于 RSA 只需要选择 $N$ 的长度，ECC 的曲线参数直接影响安全性——选择了错误的曲线（如超奇异曲线），ECDLP 就变得容易。同时，曲线的设计空间非常复杂，所以标准化的曲线（如 NIST P 系列、Curve25519）是推荐的选择。**永远不要自己发明曲线**，除非你是密码学专家并愿意承担巨大的安全风险。

### 2.5 双线性映射

#### Pairing 的基本定义

双线性映射（Pairing）是一个映射 $e: G_1 \times G_2 \to G_T$，其中 $G_1, G_2, G_T$ 都是阶为素数 $q$ 的循环群。

Pairing 的数学基础来源于代数几何中的 Weil 对和 Tate 对，但密码学中只关心其抽象性质。

**实际使用的 Pairing 类型**：

1. **Type-1**：$G_1 = G_2$（对称配对，如超奇异曲线）
2. **Type-2**：$G_1 \neq G_2$，但存在高效的同态映射 $G_2 \to G_1$
3. **Type-3**：$G_1 \neq G_2$，且无高效同态映射（目前最流行，如 BN 曲线、BLS 曲线）

**Insight**：Pairing 曾是纯数学中"没用"的结构——代数几何学家研究了 Weil 对上百年的纯粹数学性质。直到 2000 年左右，Joux、Boneh 和 Franklin 等人发现 Pairing 可以用在密码学中实现以前做不到的功能（三方一轮密钥交换、基于身份的加密）。这是"无用数学"变成"关键技术"的绝佳案例。

#### 双线性、非退化性与可计算性

**双线性（Bilinearity）**：

对任意 $P, P_1, P_2 \in G_1$、$Q, Q_1, Q_2 \in G_2$ 和 $a, b \in \mathbb{Z}_q$：

$$e(P_1 + P_2, Q) = e(P_1, Q) \cdot e(P_2, Q)$$
$$e(P, Q_1 + Q_2) = e(P, Q_1) \cdot e(P, Q_2)$$
$$e(aP, bQ) = e(P, Q)^{ab}$$

**双线性性是最核心的性质**。它意味着你能"把乘法移到指数上"——配对将椭圆曲线上的加法映射到目标群中的乘法。

**非退化性**：存在 $P \in G_1$ 和 $Q \in G_2$ 使得 $e(P, Q) \neq 1_{G_T}$（不是平凡地将所有点对映射到单位元）。

- 这保证了配对确实提供了"有用的"信息
- 如果退化，整个映射就是平凡的（所有值都是 1）

**可计算性**：存在 PPT 算法计算 $e(P, Q)$。

- Miller 算法（1986）是第一个高效的配对计算算法
- 现代配对计算在 BN256 曲线上只需数毫秒

**Insight**：三个性质缺一不可。双线性是"功能性"——没有它配对就没用；非退化是"非平凡性"——没有它配对输出没信息；可计算性是"可行性"——没有它配对就没法在实际中使用。这三个性质放在一起，使 Pairing 成为密码学中最强大的工具之一。

#### 基于 Pairing 的密码方案

**1. 三方一轮 Diffie-Hellman（Joux, 2000）**：
- Alice、Bob、Charlie 分别发布 $aP$、$bP$、$cP$
- Alice 计算 $e(bP, cP)^a = e(P, P)^{abc}$
- 三人各自得到相同的共享密钥，仅需一轮通信

**2. 基于身份的加密 IBE（Boneh-Franklin, 2001）**：
- 标识 $ID$ 的对应公钥直接从 $ID$ 派生（不需要证书）
- PKG 管理主密钥 $s$，发布 $s \cdot H(ID)$ 作为用户私钥
- 加密身份为 $ID$ 的消息：用 $e(H(ID), P_{pub})^r$ 作为共享密钥

**3. BLS 签名（Boneh-Lynn-Shacham, 2001）**：
- 签名：$\sigma = s \cdot H(m)$（一个群元素）
- 验证：$e(\sigma, g) = e(H(m), P_{pub})$
- 签名长度仅为 32 字节（对 128 比特安全）
- 支持签名聚合：$\sigma_{\text{agg}} = \sum \sigma_i$

**4. 短群签名、环签名、门限签名**等更高级的原语

**Insight**：Pairing 的引入使密码学从"两层结构"（公钥/私钥）跨越到了"三层结构"（$G_1, G_2, G_T$）。这个额外的维度允许我们构造以前不可能的功能——IBE 消除了证书管理，BLS 实现了极短签名和签名聚合。这些方案在区块链（以太坊 2.0 使用 BLS）和 IoT（证书管理简化）中找到了实际应用场景。

#### BDH 类困难假设

**Bilinear Diffie-Hellman（BDH）问题**：给定 $(P, aP, bP, cP)$ 对 $G_1$，$e(P, P)^{abc}$ 对 $G_T$，求值。

**BDH 假设**：任何 PPT 算法解决 BDH 的概率可忽略。

**Decisional BDH（DBDH）问题**：区分 $e(P, P)^{abc}$ 和 $G_T$ 中随机元素。

**BDH vs CDH/DDH**：
- BDH 是 CDH 在配对上下文中的"移植"
- DBDH 是 DDH 的配对版——用于 IND-CPA 安全的 IBE 证明
- 如果 DDH 在 $G_1$ 中容易（因为配对可计算），但 BDH/DBDH 仍然困难

**$k$-CAA 和 $q$-SDH 等问题**：
- 用于证明更复杂的方案（如 Boneh-Boyen 签名）
- 涉及多个查询的"自适应"攻击场景

**更强的假设 vs. 更弱的假设**：

- BDH 是"标准"的双线性假设
- 但有些方案需要更强的假设（如 Gap-BDH、$l$-BDHI）
- 一般来说，假设越弱（越容易满足），安全性论证越令人信服

**Insight**：引入 Pairing 后，原来在标准群中成立的 DDH 假设**不再成立**——因为我们可以用配对计算 $e(g^a, g^b) = e(g,g)^{ab}$ 并比较 $e(g,g)^{ab}$ 和 $e(g,g)^c$ 来区分 DDH 元组！这意味着基于 DDH 的证明在 Pairing 群中直接失效，需要改用 DBDH 或 BDH。这是设计 Pairing 方案时必须注意的关键点。

#### Pairing 在 IBE、ABE 和聚合签名中的作用

**IBE（身份基加密）**：

- **问题**：传统 PKI 需要 CA 颁发证书，管理成本高
- **Pairing 解决方案**：用户的公钥就是其身份（如 email 地址）的哈希值，PKG 用主密钥生成用户的私钥
- **Pairing 的核心作用**：使发送方能用接收方的身份和 PKG 的公钥加密，而接收方用自己的私钥解密

**ABE（属性基加密）**：

- **问题**：需要"细粒度"的访问控制——只有满足特定属性条件的用户才能解密
- **Pairing 解决方案**：
  - KP-ABE：密文关联属性集，密钥关联访问策略
  - CP-ABE：密钥关联属性集，密文关联访问策略
- **Pairing 的核心作用**：通过配对计算实现"策略验证"的密码学化——访问结构被编码为多项式/秘密共享，配对验证属性是否满足策略

**聚合签名**：

- **问题**：$n$ 个不同签名者对 $n$ 条消息签名，验证需要 $n$ 次配对
- **BLS 签名聚合**：$\sigma = \sum_{i=1}^n \sigma_i$，验证只需 $O(n)$ 次配对
  $$e(\sigma, g) = \prod_{i=1}^n e(H(m_i), PK_i)$$
- **更进一步**：还可以做多方聚合、门限聚合

**Pairing 在区块链中的应用**：
- 以太坊 2.0 的共识层使用 BLS 签名聚合验证器签名
- Zcash 使用 Pairing 实现零知识证明（Groth16）
- 跨链桥和原子交换等高级协议

**Insight**：Pairing 的独特价值在于它**在群之间建立了乘法关系**。在普通群中，你可以对消息签名（离散对数），但不能"验证"两个独立签名之间的关系。而 Pairing 允许我们在不知道私钥的情况下验证代数关系——这正是 IBE 和聚合签名等高级原语所需要的。可以毫不夸张地说，Pairing 开启了"密码学的第三波浪潮"（第一波是公钥密码，第二波是可证明安全，第三波是基于 Pairing 的功能性密码）。
