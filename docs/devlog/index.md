## 日志模板

固定模板：先写背景，再按 Problem / Decision / Why / Result 四段展开。一段记录一个问题，多个问题就复制四段结构。

```md
# YYYY-MM-DD：日志标题

> 一句话背景：这段日志记录在什么上下文 / 项目 / 阶段下发生。

## Problem（问题）

现状是什么？卡点 / bug / 需求是什么？尽量给出可复现或可测量的描述。

## Decision（决定）

我最终做了什么选择？改了哪些文件 / 配置 / 流程？

## Why（原因 / 考量）

为什么是这个方案？比较过哪些替代方案（方案 A / B / C）？各自取舍是什么？选它的理由是什么？

## Result（结果）

效果如何？验证方式（测试 / 线上验证 / 数据）？有什么代价或后续注意点？
```
