# DAPO：让长推理强化学习真正训练起来

## 一句话结论

**DAPO（Decoupled Clip and Dynamic sAmpling Policy Optimization）沿用 GRPO 的组内优势与 PPO 式裁剪更新，通过不对称裁剪、动态采样、Token 级损失聚合和超长奖励塑形，改善长推理训练中的探索、有效梯度、长度权重与截断噪声。它的价值是一套相互配合的训练方法，而不只是修改一个裁剪参数。**

上一篇 [GRPO：从 PPO 到组相对策略优化](/daily/2026/10/2026-10-20-daily-grpo)讲了如何用组内奖励替代 Critic。本文进一步解释：**有了正确的基本公式，为什么大规模长推理训练仍可能失败？DAPO 分别在哪些环节补上了什么？**

以下以 [DAPO 原论文 v1](https://arxiv.org/html/2503.14476v1) 的算法、实验为依据，并结合 [verl 的 DAPO 实现文档](https://verl.readthedocs.io/en/latest/algo/dapo.html)解释工程中的聚合与过滤约定。论文的主要实验场景是 Qwen2.5-32B 上的数学推理强化学习。

## 1. 从 GRPO 出发：长回答为什么会放大训练问题？

先复习两个核心量。对于同一道题的第 $i$ 条回答、第 $t$ 个 Token：

$$
\rho_{i,t}(\theta)
=\frac{\pi_\theta(y_{i,t}\mid q,y_{i,<t})}
{\pi_{\mathrm{old}}(y_{i,t}\mid q,y_{i,<t})}
$$

$$
\hat A_i
=\frac{R_i-\bar R}{\sigma_R+\eta}
$$

其中，$\pi_{\mathrm{old}}$ 是生成这批数据的行为策略，$\bar R$ 与 $\sigma_R$ 是同题候选奖励的均值和标准差，$\eta$ 用于防止除零。结果监督下，同一条回答的全部 Token 共享优势 $\hat A_i$。

原始 GRPO 用对称区间 $[1-\epsilon,1+\epsilon]$ 裁剪，先平均每条回答内部的目标，再对回答平均。将它用于数千甚至上万 Token 的长推理时，会遇到几类相互影响的问题：

| 训练现象 | 问题来源 | DAPO 的主要改动 |
| --- | --- | --- |
| 模型越来越确定，候选回答趋同 | 有价值的低概率选择不容易被充分强化，探索不足 | Clip-Higher |
| 一批题里很多全对或全错组 | 相同奖励导致组内优势为零，有效训练批次缩水 | Dynamic Sampling |
| 长回答中的 Token 信号被稀释 | 每条回答等权，单个 Token 的权重与长度成反比 | Token-Level Policy Gradient Loss |
| 推理尚未完成，就因长度上限被统一判罚 | 外部截断与推理质量混在同一个奖励信号中 | Overlong Reward Shaping |

DAPO 仍然不训练 Critic，也没有放弃 PPO 式代理目标。它主要是在回答：**哪些数据进入更新、每个 Token 占多大权重，以及允许什么方向的策略变化。**

## 2. Clip-Higher：给有价值的低概率选择更多上升空间

### 2.1 对称裁剪为什么可能限制探索？

PPO-Clip 与原始 GRPO 使用的单 Token 目标为：

$$
\ell_{\mathrm{sym}}(\rho,A)
=\min\left(
\rho A,\;
\operatorname{clip}(\rho,1-\epsilon,1+\epsilon)A
\right)
$$

对正优势样本，当 $\rho>1+\epsilon$ 后，该项不再鼓励继续提高这个 Token 的概率。

假设一段成功推理中出现了一个有用但少见的 Token，其旧概率为 0.01。设 $\epsilon=0.2$，那么正优势目标在概率达到：

$$
0.01\times1.2=0.012
$$

之后进入裁剪平台。这只是 0.002 的绝对概率变化。相比之下，同样的相对比例作用在旧概率 0.5 上，对应的平台起点是 0.6，绝对变化为 0.1。

这并不证明每个低概率 Token 都值得鼓励，但说明**相同的比例阈值，对低概率选择只留出较小的绝对上升空间**。长推理需要探索不同解法，如果策略过早集中到少数高概率路径，就可能在尚未找到更好策略时失去多样性。

### 2.2 DAPO 把上下界分开设置

DAPO 使用：

$$
\ell_{\mathrm{asym}}(\rho,A)
=\min\left(
\rho A,\;
\operatorname{clip}(\rho,1-\epsilon_{\mathrm{low}},1+\epsilon_{\mathrm{high}})A
\right)
$$

原论文实验取：

$$
\epsilon_{\mathrm{low}}=0.2,
\qquad
\epsilon_{\mathrm{high}}=0.28
$$

也就是把对称区间 $[0.8,1.2]$ 改成 $[0.8,1.28]$：

- **提高上界：**正优势 Token 可以在该项仍有激励的范围内获得更大的概率增幅。
- **保留下界：**不同时加大负优势 Token 被压低的空间，避免过快收缩采样分布。

对刚才旧概率为 0.01 的 Token，平台起点从 0.012 变为 0.0128。它没有突然变成高概率动作，但在多轮采样、强化的过程中，约束方式发生了持续作用。

这里的“上界”始终指**裁剪目标开始饱和的位置**，不是模型概率的硬限制；其他样本与参数共享仍可能使概率继续变化。

### 2.3 Clip-Higher 不等于“熵越高越好”

策略熵可以写成：

$$
H(\pi(\cdot\mid s))
=-\sum_v\pi(v\mid s)\log\pi(v\mid s)
$$

熵过低，模型可能只重复少数路径；熵过高，则可能出现乱码、重复和无效探索。Clip-Higher 没有直接要求“把分布变均匀”，它通过奖励相关的更新，让**被采样到、且属于正优势回答的选择**有更多强化空间。

这是一种改善探索的经验机制，不是保证熵单调增长或性能必然提高的定理。需要把熵、回答质量和长度放在一起观察。

## 3. Dynamic Sampling：保持有效训练组，而不是只保持名义 Batch 大小

### 3.1 全对组与全错组为什么都可能浪费更新？

先考虑只有二值正确性奖励的情况。原论文使用正确为 $+1$、错误为 $-1$；忽略稳定项时，它与 0/1 奖励经过组内标准化后得到相同优势。

假设每题生成 4 个回答：

| 题目组 | 正确性 | 是否有组内奖励差异 |
| --- | --- | --- |
| A | `[1, 1, 1, 1]` | 没有，优势均为 0 |
| B | `[0, 0, 0, 0]` | 没有，优势均为 0 |
| C | `[1, 0, 1, 0]` | 有，能提供相对信号 |
| D | `[0, 0, 0, 1]` | 有，能提供相对信号 |

名义上这一批有 4 道题、16 条回答，实际上只有两组提供正确性对应的策略梯度。随着模型掌握更多训练题，全对组还可能持续增加，使有效批次变小、梯度更不稳定。

### 3.2 动态采样怎样填满一个批次？

DAPO 在本轮候选组中，过滤全对与全错的组，只保留满足以下条件的组：

$$
0<\sum_{i=1}^{G}\mathbf{1}[y_i\text{ 正确}]<G
$$

然后继续采样更多题目及其候选，直到收集到目标数量的有效组：

```text
设目标为收集 3 个有效组：

第一批：A 全对 → 丢弃
        B 全错 → 丢弃
        C 混合 → 保留
        D 混合 → 保留

第二批：E 全对 → 丢弃
        F 混合 → 保留

得到 C、D、F 三个有效组，进入策略更新。
```

这里过滤的是**整组**，不是只保留正确回答。C、D、F 中的失败候选仍然参与训练，它们提供降低不良路径概率的负优势。

这也不是永久删除某道题：某个全错组可能只是本轮没采样到成功回答。策略变化后，同一道题在后续轮次仍可能产生混合结果。

### 3.3 有效组越少，采样成本会怎样增长？

若为了直觉分析，假设同题每条回答独立、正确概率相同且为 $p$，则一个大小为 $G$ 的组被保留的概率为：

$$
P_{\mathrm{active}}=1-p^G-(1-p)^G
$$

例如 $G=4$：

- $p=0.5$ 时，有效组概率为 $87.5\%$。
- $p=0.99$ 时，有效组概率约为 $3.94\%$，平均要生成约 25.4 个候选组，才能得到一个有效组。

真实题目难度并不相同，候选间也可能存在相关性，但这个计算揭示了一个重要代价：**动态采样把零信号组从优化批次中移走，并没有消除生成这些组的成本。**

因此它提高的是有效更新的密度，不保证采样 Token 数、总 GPU 时间都减少。它还改变了实际训练分布，使本轮能产生结果差异的题目获得更多更新机会。

实际实现需要采样轮数上限，并记录保留率。如果几乎找不到有效组，应检查数据难度、采样多样性与组大小，而不是无限等待。

加入连续长度奖励后，即使正确性全相同，最终奖励也可能不同。此时按 `acc` 过滤还是按最终奖励方差过滤，会形成不同变体；verl 文档允许配置过滤指标，需要明确记录选择。

## 4. Token 级损失：同样一个 Token，为什么要受回答长度影响？

### 4.1 原始 GRPO 是“回答等权”

暂时忽略 KL。设一个小批次有 $N$ 条回答，第 $i$ 条长度为 $T_i$，每个 Token 的裁剪目标为 $\ell_{i,t}$。原始 GRPO 式聚合为：

$$
J_{\mathrm{seq}}
=\frac1N\sum_{i=1}^{N}
\left(\frac1{T_i}\sum_{t=1}^{T_i}\ell_{i,t}\right)
$$

它先计算一条回答内部的均值，再对回答取均值。因此，每条回答的总显式权重相同，而该回答中单个 Token 的权重是 $1/(NT_i)$。

考虑两条长度分别为 100 和 900 的回答：

| 权重 | 100 Token 的回答 | 900 Token 的回答 |
| --- | --- | --- |
| 整条回答总权重 | $1/2$ | $1/2$ |
| 每个 Token 权重 | $1/200$ | $1/1800$ |

短回答里的单个 Token，显式系数是长回答中单个 Token 的 9 倍。

对于长推理，这既可能稀释长成功轨迹中的有用模式，也可能使长失败轨迹中大量重复、乱码等模式受到的逐 Token 抑制偏弱。

### 4.2 DAPO 改成“有效 Token 等权”

DAPO 使用 Token 级聚合：

$$
J_{\mathrm{token}}
=\frac{\sum_{i=1}^{N}\sum_{t=1}^{T_i}\ell_{i,t}}
{\sum_{i=1}^{N}T_i}
$$

对刚才两条回答，每个 Token 的显式系数都是 $1/1000$；两条回答按 Token 数计算的总权重分别为 10% 与 90%。

要准确区分两件事：

1. **优势来源没有因此变细。** 仍然可以是一条回答共享一个 $\hat A_i$，不是为每个 Token 新增一个奖励模型。
2. **聚合权重变了。** 长回答包含更多 Token，因此在总目标中拥有更大的累计权重；并不是把每条回答总权重也保持相同。

而且“Token 等权”只表示聚合系数相同，实际梯度还受优势大小、概率比、是否被裁剪以及模型导数影响。

### 4.3 掩码与归一化必须一起算

设 $m_{i,t}$ 表示参与训练的有效回答 Token，则实际写法是：

$$
J_{\mathrm{token}}
=\frac{\sum_{i,t}m_{i,t}\ell_{i,t}}
{\sum_{i,t}m_{i,t}}
$$

Prompt、Padding 和被明确屏蔽的位置，既不能进入分子，也不能进入有效 Token 分母。verl 的 `token-mean` 在小批次内跨序列聚合；如果改成每组先独立归一化，再对组等权平均，又会改变不同题目组之间的权重。

多卡或梯度累积时也需要核对这个定义：若各分片有效 Token 数不同，简单平均各分片的局部均值，不等价于整个批次的有效 Token 均值。

## 5. 超长奖励塑形：把“推理错误”与“超出预算”拆清楚

### 5.1 截断不是完整回答的自然结束

生成时必须设置长度上限。假设模型推理方向合理，但还没输出答案就达到上限，如果直接给它与错误答案相同的惩罚，反馈里就混入了两类原因：

- 解题过程或答案确实错误。
- 推理还未完成，被外部资源上限截断。

仅根据被截断的前缀，通常无法判断继续生成后会不会成功。统一重罚可能让模型把某些合理推理模式也当成错误来源。

原论文先研究了 **Overlong Filtering**：屏蔽被截断样本的损失，减少这类奖励噪声。它能避免部分错误归因，但也丢掉了对这些轨迹的直接学习信号。

### 5.2 软惩罚让长度约束逐步生效

DAPO 进一步使用 **Soft Overlong Punishment**。设：

- $L_{\mathrm{hard}}$：生成的硬长度上限。
- $L_{\mathrm{cache}}$：接近上限时的软惩罚区间长度。
- $L_{\mathrm{soft}}=L_{\mathrm{hard}}-L_{\mathrm{cache}}$：开始惩罚的长度。

把原论文的长度惩罚用等价的边界约定写成：

$$
R_{\mathrm{len}}(T)=
\begin{cases}
0,& T\le L_{\mathrm{soft}}\\
-\dfrac{T-L_{\mathrm{soft}}}{L_{\mathrm{cache}}},
& L_{\mathrm{soft}}<T<L_{\mathrm{hard}}\\
-1,& T\ge L_{\mathrm{hard}}
\end{cases}
$$

然后与正确性奖励相加：

$$
R_i=R_{\mathrm{correct},i}+R_{\mathrm{len}}(T_i)
$$

原论文实验的硬生成上限为 20,480 Token，软惩罚区间为 4,096 Token，所以从 16,384 Token 开始惩罚：

| 回答长度 | 长度惩罚 | 如果完整回答正确，正确性奖励为 $+1$ 时的总奖励 |
| --- | --- | --- |
| 12,000 | 0 | 1 |
| 16,384 | 0 | 1 |
| 18,432 | -0.5 | 0.5 |
| 20,480 | -1 | 0 |

最后一列的前提是**确实能验证完整答案正确**。被截断而没有最终答案的回答，不能因为“也许再写下去会对”就获得正确奖励。

这项机制表达的是：在任务完成之外，还希望模型控制接近资源上限的长度。它不是奖励所有短回答，也不意味着“推理越短越好”；在软阈值之前，长度项完全不区分 1,000 和 10,000 Token。

### 5.3 过滤与塑形不要混成同一条规则

Overlong Filtering 是屏蔽部分样本损失；软惩罚是修改奖励，再通过组内优势影响更新。它们的作用位置不同。

verl 的 DAPO 文档特别说明，其配方没有实现 Overlong Filtering，并指出论文中多数实验、包括最佳设置，并不依赖这一额外过滤，因为它与奖励塑形的作用有所重叠。因此复现时不能默认“DAPO 必须同时屏蔽全部超长样本，并给这些样本加长度惩罚”。

还要记录 EOS 自然结束与达到硬上限的截断标记，仅看 Token 数是否相同，可能无法区分两种结束原因。

## 6. DAPO 为什么移除了参考 KL？

原始 GRPO 包含相对于冻结参考模型的 KL 正则。DAPO 在其长推理数学训练设置中移除了这项约束，理由是希望策略能够明显偏离初始模型，形成新的长推理行为。

但移除的是**当前策略与参考策略之间的 KL 项**，没有移除当前策略与行为策略的概率比，也没有移除裁剪：

| 机制 | 比较谁 | 主要目的 |
| --- | --- | --- |
| 新旧概率比与裁剪 | 当前策略 vs 生成本批数据的旧策略 | 控制一批数据上策略更新的激励 |
| 参考 KL 正则 | 当前策略 vs 阶段内冻结的参考策略 | 控制偏离初始行为的程度 |

因此，“不用参考 KL”不等于“完全不约束更新”，但裁剪也不保证严格的策略距离上限。

这同样不是对所有任务都成立的结论。如果任务要求保持某些原有行为，移除参考约束可能改变质量取舍；而 PPO-Clip 本身也不强制包含冻结参考模型。应该比较完整配方，而不是把“有无参考 KL”当成 PPO 与 DAPO 的定义边界。

## 7. 把四项改动合成完整训练流程

令 $\mathcal B$ 表示动态采样后进入更新的回答小批次，每条回答仍在自己的题目组内计算优势。结合 Token 掩码，优化目标可写为：

$$
J_{\mathrm{DAPO}}(\theta)
=\mathbb{E}_{\mathcal B}
\left[
\frac{\sum_{i\in\mathcal B}\sum_t
m_{i,t}\ell_{\mathrm{asym}}(\rho_{i,t}(\theta),\hat A_i)}
{\sum_{i\in\mathcal B}\sum_t m_{i,t}}
\right]
$$

这里各项的来源是：

- **$\mathcal B$：**由动态采样及过滤构造。
- **$\hat A_i$：**由正确性及长度塑形后的奖励做组内标准化。
- **$\ell_{\mathrm{asym}}$：**使用独立的上下裁剪范围。
- **分母：**采用该小批次的有效回答 Token 总数。
- **参考 KL：**原论文 DAPO 设置中不加入。

原论文以单题组内的 Token 归一化展示目标；上式按 verl `token-mean` 的小批次聚合方式展开。复现时要同时确认论文记号与代码实际聚合范围。

最小流程如下：

```text
固定本轮旧策略，准备空的有效组缓冲区。

重复采样，直到有效组数达到目标或触及采样上限：
  抽取一批题，每题生成 G 个候选。
  保存旧 Logprobs、Token 掩码、长度与结束原因。
  计算正确性，按约定指标过滤无效组，保留组内全部候选。

对保留回答加入长度惩罚，按题目组计算最终奖励与优势。
在有限次小批量更新中：
  重算当前 Logprobs，计算新旧概率比。
  应用不对称裁剪，并按有效 Token 聚合策略损失。
  反向传播更新策略，然后进入下一轮采样。
```

长度奖励也可以在过滤前计算，关键是明确**过滤使用哪个指标**，以及优势最终使用哪一种奖励。奖励、优势和旧概率在本轮策略优化中均应固定，不随反向传播更新。

四项机制互相配合：Clip-Higher 增加探索空间，但不应任由无效长回答膨胀；Token 级损失更充分地学习或抑制长轨迹；长度塑形控制接近预算的行为；动态采样则维持有效比较信号的密度。

## 8. 与 PPO、GRPO 放在一起看

下面的 PPO 指典型 Actor-Critic PPO，GRPO 指原始结果监督形式，DAPO 指本文解释的原始配方：

| 维度 | PPO | GRPO | DAPO |
| --- | --- | --- | --- |
| 优势来源 | 价值函数与回报，常用 GAE | 同题候选奖励标准化 | 沿用组内标准化 |
| Critic | 通常训练 | 不训练 | 不训练 |
| 同题多候选 | 非必要 | 核心组成 | 核心组成，并动态筛选组 |
| 裁剪范围 | 常见为对称 | 原始形式为对称 | 上下界解耦，提高上界 |
| Token 信用分配 | 可随状态变化，依赖价值估计 | 结果监督下整条回答共享优势 | 仍可共享优势，没有自动变成过程监督 |
| 损失聚合 | 随具体实现而异 | 原始形式先序列内均值，再序列均值 | 有效 Token 均值 |
| 无效奖励组 | 不依赖组内差异来定义优势 | 可能产生零优势组 | 过滤并继续采样补齐 |
| 参考 KL | LLM 配方常加入，非算法必需 | 原论文有 | 原论文设置中移除 |
| 长度处理 | 依具体奖励及终止约定 | 依具体实现 | 显式讨论并加入超长奖励塑形 |

### 相比 PPO，DAPO 的主要取舍是什么？

它继承了 GRPO 不训练 Critic 的优势，避免价值学习带来的开销与不稳定因素。但也继承了组内比较的局限：需要多个候选，结果监督的信用分配仍粗糙，极难题可能找不到任何成功路径。

动态采样会额外消耗候选生成成本；Token 级聚合会提高长轨迹的累计权重；移除参考 KL 允许更大行为变化。这些都是明确的训练选择，不是无条件占优。

更合理的判断方式是：

> **如果主要难点是可靠的价值估计，GRPO/DAPO 有吸引力；如果主要难点是长推理中的探索、零信号组和长度处理，DAPO 提供了更具体的改进配方。**

PPO 的价值函数仍有状态相关估计与信用分配上的潜力，不能仅凭某次数学实验就断言它在所有任务上落后。

## 9. 原论文实验说明了什么？

DAPO 论文在 Qwen2.5-32B Base 上训练，使用约 17K 道数学题构建的 DAPO-Math-17K 数据。数据经过筛选与改写，使答案为整数，降低规则解析复杂表达式引入的误差；这说明可靠的验证信号也是结果的重要条件。

原论文报告的渐进改进结果如下：

| 累积设置 | AIME 2024，avg@32 |
| --- | --- |
| Naive GRPO | 30 |
| + Overlong Filtering | 36 |
| + Clip-Higher | 38 |
| + Soft Overlong Punishment | 41 |
| + Token-level Loss | 42 |
| + Dynamic Sampling，DAPO | 50 |

评估将题集重复采样 32 次，以平均正确率降低随机性。**avg@32 不是“32 次里只要有一次答对就算成功”的 pass@32，也不是多数投票成绩。**

论文还将 DAPO 的 50 分与 DeepSeek-R1-Zero-Qwen-32B 的 47 分比较，并报告使用约一半训练步数。解读时需要保留三个条件：

1. **这是特定基础模型、数据、奖励与评估设置下的结果。** 不是所有 PPO、GRPO 实现的统一排名。
2. **表格是逐步叠加配方的结果。** 不能把分数差直接解释成每个模块独立、可相加的普遍收益。
3. **训练步数不等于总成本。** 动态采样候选数、回答长度、生成并行策略与硬件都会影响实际 GPU 时间。

论文的 rollout 配置是每批 512 道题、每题 16 个候选。这个规模本身就说明，长推理 RL 同时依赖采样系统与优化实现，只有损失公式还不足以复现结果。

## 实践建议：用哪些指标判断真的训练好了？

| 指标 | 帮助发现什么问题 |
| --- | --- |
| 独立验证集正确率 | 训练奖励提高是否转化为泛化收益 |
| 全对组、全错组、有效组比例 | 动态采样是否越来越难补齐批次 |
| 每个有效组消耗的候选数与 Token 数 | 有效梯度密度提升付出了多少采样成本 |
| 回答长度均值、分位数、截断率 | 是否出现长尾膨胀、重复或频繁耗尽预算 |
| 策略熵与候选多样性 | 是否探索坍缩，或反过来出现无效高熵生成 |
| 上、下裁剪比例及新旧策略偏移 | 一批数据是否被重复优化过度 |
| Token 级损失的全局分母 | 多卡和梯度累积是否改变了实际样本权重 |

实际落地时可以遵循以下顺序：

1. **先把验证器与截断语义做对。** 区分错误、未完成、格式解析失败与自然结束，抽查奖励是否对应真实任务结果。
2. **建立可解释的 GRPO 基线。** 固定模型、数据与预算，先确认组内优势、概率比和掩码计算正确。
3. **逐项加入改动。** 同时观察验证正确率、有效组比例、熵和长度，避免只按训练奖励判断好坏。
4. **为动态采样设置上限。** 保留率过低时，检查任务难度和采样策略；把额外生成成本计入预算。
5. **固定聚合与归一化约定。** 特别记录 `token-mean` 的范围、全局有效 Token 计数和过滤指标，防止名字相同、实际目标不同。

最终可以把 DAPO 记成四个问题的答案：**有价值的少见选择能否被强化？每批是否有足够比较信号？长回答中的 Token 是否得到合适权重？长度上限是否制造了错误奖励？** 它相较 PPO、GRPO 的主要贡献，就是把这些问题落实成可以分析、实现和验证的训练机制。
