# 技术方向

## Agent Engineering

使用 LangGraph、Azure OpenAI、Pydantic 与 FastAPI 构建 Agent 应用，实践 Planner–Evaluator–Executor 分层架构、插件化 Skill、Human-in-the-Loop、Checkpoint 状态恢复与多层降级机制。

## 后端工程

熟悉 Python、Java 与 Node.js 后端开发，使用 FastAPI、Spring Boot 3、SQLAlchemy、MyBatis-Plus、MySQL、Redis、Milvus 与 MinIO；具备异步任务、分布式锁、缓存、限流、容器化部署和可观测性实践。

## 计算机视觉

实践 RT-DETR v3 小目标检测、U-Net 分割、CLIP 特征匹配、TransNetV2 镜头检测、单应性变换、轨迹平滑和智能裁切，并使用 FFmpeg 与 faster-whisper 构建完整视频处理链路。

## 密码学与隐私计算

研究方向为应用密码学；实践属性基加密（ABE）、细粒度访问策略与安全文件共享，同时关注多方安全计算、同态加密、联邦学习和可信执行环境。

## 前端与工程化

使用 React 19、Vue 3、Vite、Zustand 与 Element Plus 开发 Web 应用，使用 Electron、pywebview 和 Playwright 构建桌面端及浏览器自动化能力；熟悉 Docker Compose、Kubernetes、NFS 与 GPU 服务部署。
