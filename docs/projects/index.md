# 项目实践

项目不是结果陈列柜，而是记录问题、约束、决策与迭代的地方。

## 项目列表

### [Wenjian](./wenjian)

简历驱动的 AI 模拟面试平台

每一段简历，都值得被认真追问
基于你的真实经历生成个性化问题，通过连续追问、回答评分和证据分析，还原更接近真实面试的训练过程。

### [商业定价智能助手 Auto-PDP](./auto-pdp)

基于 LangGraph 与 Azure OpenAI 的商业定价 Agent，支持价格模拟、根因分析和合同信息查询。

### [足球追踪系统](./football-tracking)

FIFA 赛事短视频自动化生产系统，覆盖回放检测、足球追踪、智能裁切、语音识别和多比例视频生成。

### [安全文件共享系统](./file-upload)

结合属性基加密与可靠大文件上传能力，实现细粒度访问控制和多种安全分享模式。

### [FindJob：AI 求职助手](./findjob)

覆盖简历解析、岗位混合检索、智能推荐与自动填表的全栈 AI 求职产品。

### [大语言模型空间推理研究](./spatial-reasoning)

结合 Q-learning 与逆向课程学习增强大语言模型的多步空间关系推理能力。
