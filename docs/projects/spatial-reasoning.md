# 强化学习增强大语言模型空间推理能力

**角色：主要负责人** · `2024.02—2024.06`

## 研究问题

针对大语言模型在相对方位判断和多步空间关系推理任务中准确率不足、复杂样本收敛困难的问题，提出将空间关系转换为社交关系网络的统一表示方法。

## 方法

结合 Q-learning 与逆向课程学习设计训练策略，从目标状态反向构造难度递增的样本，提高复杂空间推理任务的训练效率和收敛稳定性。

## 结果

- 负责问题建模、算法设计、实验实现、对比分析与论文撰写
- 在对应实验设置下，任务成功率由 **23% 提升至 40%**
- 相关研究成果发表于 **ICIC** 与 **Scientific Reports**
