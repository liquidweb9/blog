# 论文原稿库

存放研读使用的论文 PDF、补充材料与原始附件。目录位于仓库根目录，独立于 VitePress 的 `docs/`，不会随博客构建发布。

Git 仅跟踪本说明和 `sources.md` 来源索引，其余内容均已忽略。论文正文、配图和分析仍按博客约定放在 `docs/papers/`。

## 目录约定

```text
paper-originals/
├── README.md
├── sources.md
└── llm-agents/                   # 与专栏方向目录名一致
    └── 2025-weaver/
        ├── paper.pdf            # 论文正文
        ├── supplement.pdf       # 补充材料（如有）
        └── source.txt           # 本地记录下载时间、原始地址与版本（可选）
```

方向沿用 `llm-agents`、`computer-vision`、`systems`、`cryptography`。论文目录使用「发表年份 + 简称」，阅读日期记录在博客文章中。

## 使用坚果云

坚果云可作为原稿库的同步和备份位置：

1. 在坚果云桌面客户端中，将本地 `paper-originals/` 目录设置为同步文件夹。
2. 将论文和补充材料保存到对应论文目录，等待客户端完成同步。
3. 在 `sources.md` 中记录官方链接、实际使用的版本和本地路径；需要对外分享时，再补充坚果云分享链接。
4. 换设备阅读时，通过坚果云同步取得文件。Git 克隆只包含本说明和来源索引，不包含 PDF。

也可以把 PDF 保存在已有的坚果云同步目录中，在索引中记录位置，阅读时再复制到本目录。

博客文章优先引用 OpenReview、arXiv、出版社或作者主页等原始地址。坚果云分享页作为补充下载入口，可能受登录、分享设置或服务调整影响；不将其作为文章插图地址。

## 原稿与博客配图

- **论文原稿**：放在本目录或坚果云中，不进入 Git，不进入站点部署产物。
- **来源记录**：放在 `sources.md` 中，便于明确文章依据的论文版本。索引会进入 Git，适合记录公开来源和公开分享地址。
- **博客配图**：从原稿中提取需要讲解的图，放到 `docs/papers/<方向>/images/<论文简称>/`，标注原图号和出处，随文章发布。
- **文章链接**：使用论文官方 URL；本地 `paper-originals/` 路径只是写作资料位置，不能作为网站下载链接。

首次获取原稿后，在索引中补齐版本与文件位置即可。
