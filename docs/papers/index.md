# 论文研读札记

读懂一篇论文，不止是记住结论，更要弄清它为什么提出这个问题、方法如何起作用，以及这些思路还能走向哪里。

这里按研究方向积累日常阅读的论文。每篇札记沿着「问题 → 贡献 → 方法 → 证据 → 思考」展开，结合原文图表、具体场景和已有知识，留下可以反复查阅的理解。

## 每篇札记写什么

1. **全文概览**：先讲清楚通过什么方法，解决了什么问题，在什么条件下取得了什么效果。
2. **背景与问题场景**：交代任务、约束与已有方法的不足，用具体例子说明问题为什么存在。
3. **贡献逐项分析**：对照已有工作拆解每项贡献，分别说明适用场景、关键变化、价值与证据。
4. **方法详解**：结合论文原图解释模块和数据流，尽可能详细地走完输入、处理、中间结果到输出的全过程，补充必要公式、例子与个人见解。
5. **实验简析**：简要分析实验设置、主要结果、消融和失败案例，说明结果支持哪些结论、还有哪些边界。
6. **总结与后续方向**：联系已经学过的知识，提炼可迁移的认识，提出有依据、能够通过小规模实验检验的后续方向。
7. **延伸阅读**：串联前置知识、直接相关工作和后续研究，说明每份材料为什么值得读。

## 开始一篇新的研读

使用 [论文研读模板](./template) 创建文章。目录约定如下：

```text
docs/papers/
├── index.md                 # 专栏总览
├── template.md              # 写作说明与可复制模板
├── llm-agents/              # 大模型与智能体
│   └── index.md
├── computer-vision/         # 计算机视觉与多模态
│   └── index.md
├── systems/                 # 系统与后端
│   └── index.md
└── cryptography/            # 密码学与隐私计算
    └── index.md
```

文章命名为 `YYYY-MM-DD-paper-slug.md`，放在对应方向目录下。论文配图随文章保存在该方向的 `images/paper-slug/` 中，保留原图编号与出处。

完成后，在方向索引和站点侧边栏中添加入口。带有有效发布日期且 `listed: true` 的文章会自动进入首页最近更新和 RSS。
